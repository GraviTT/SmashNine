## Method (every row)
1. **Anchor first, per character.** Generate the character's `idle` (4 frames) anew as one sheet. Image 1 = the idle frame of the current game sheet enlarged ×4 nearest (identity, proportions, head ratio, side view, pixel finish — do not copy its pose), Image 2 = `assets/art/<id>/<stem>_illustration.png` or the shared illustration (identity only). Normalise with `tools/sprite_pipeline/normalize.py --scale-by height:<median body height of the current idle row>`; record the printed factor. This factor is the character's scale for **every** other motion (`--scale-by fixed:<factor>`), which keeps the head size the same (D32 ②) without measuring heads per frame.
2. **One motion = one generated image**, all frames together: 512×512 cells, 4 per row (2048×1024; 6 frames → 3×2 = 1536×1024), right-facing **side view** like the game sheets, poses in place, same scale and same floor line in every cell, airborne cells lifted by the jump, no per-cell resizing. For rows after idle, Image 1 = the accepted idle anchor sheet (size and look), Image 2 = the current game row (what the move is; do not copy its drawing).
3. **Prompt structure (CuSurvive §3):** `Use case: stylized-concept` · input image roles · primary request (row name, frame count, fps) · **one line per frame describing the pose** (contact/anticipation/active/follow-through/recover; hair, cape, skirt lag one frame; chibi arms: no adult arm swing, fists never cover the face) · subject invariants (face, eye colour, hair shape, accessories, armour/clothes layers, colours — list them from the sheet and README; "same head size and body width in every frame") · layout · background flat chroma green `#00FF00`, no shadow, floor, grid or text · style: crisp console pixel art for a 128-px game sprite, chunky clusters, 1-px dark outline, limited palette, no blur, gradient or anti-aliasing · final list: exact frame count, one head, two arms, two hands, weapon intact, **no effects** (no slash arcs, glows, sparks, dust — the game draws them), no text.
4. `tools/sprite_pipeline/prepare_raw.py` if the green is uneven or grid lines appear, then `normalize.py` with the character palette (`tools/sprite_pipeline/palettes/<stem>.json`), `--bg #00ff00`, `--reference smash-nine-prototype/assets/art/<id>/<sheet>.png:<row>:<frames>`. If a frame does not fit, regenerate that motion (tighter pose) — never shrink one frame, never move or paint limbs, never paste parts.
5. Up to 2 generations per motion. Keep the best; say what is still wrong.
