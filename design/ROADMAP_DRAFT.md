# Smash Nine Realms — 로드맵 초안 (토론용, 2026-10-06)

작성: Claude (리드). 이 문서는 Codex와의 토론 입력이다. 확정본은 토론 후 `design/ROADMAP.md`와 `design/DECISIONS.md`로 남긴다.

## 배경

- 프로젝트는 초기 기획 후 본격화 전에 약 3개월 중단됐다. 확정된 것도, 취소된 것도 없다.
- 사용자는 리드(Claude)에게 "Codex와 토론 후 알아서 판단해서 프로토타입을 진행"하라고 위임했다.
- 기준 문서 후보 3개가 서로 다르다.
  - `smash-nine/GAME_DESIGN_DOCUMENT.md` (6/19, Rev 1.45, 한국어 GDD, 20인 로스터·HP² 넉백·유령 장난)
  - `smash-nine/Concept1.png`, `Concept2.png` (컨셉 아트 2장: 9렐름 지도, 타임라인, 소울 성장, 20인 로스터, 팀전, 아트 스타일)
  - `smash-nine-prototype/FINAL_GAME_GOAL.md` (7/1, 영어, 가장 최신. 넉백=공간 장악, 중앙 렐름은 후반 개방)
- 실제 구현은 `smash-nine-prototype/` (Godot 4.7, GDScript ~7,000줄).

## 현재 구현 요약 (검증됨)

- 캐릭터 4종(Frey/Yuki/Luna/Nova) J/K/L/I 완성, 공통 `PlayerBase.gd`(코요테, 버퍼, 공중 점프, 하강 통과, 가드/패리, 히트스톱, 무게 넉백)
- 9렐름 3×3. 각 렐름 3840×2160 = 1280×720 레이아웃 하나를 3×3 타일로 반복. 포털(Q), 붕괴 경고 18초 → 붕괴, 42초 간격, 중앙 210초 개방
- 봇 AI(`EnemyAI.gd` 834줄), 중립 몬스터 렐름당 18마리(총 162), EXP→Lv.10 자동 스탯 성장
- 헤드리스 테스트 4개 통과. 7분 소크: 에러 1건(`Projectile.gd:55` 시그널 중 monitoring 변경)
- 없음: 승리/탈락(HP 0 → 3초 후 무한 리스폰), 결과 화면, 소울 3회 선택, 렐름 기믹, 타이틀/캐릭터 선택, 사운드, 패드, 렌더러 미지정(Forward+), export preset
- 현재 타임라인: 외곽 8개가 하나씩 붕괴, 마지막 붕괴 약 473초(7분 53초), 이후에도 끝나지 않음
- 최대 4명(목표 16명)
- `Main.gd` 1,231줄에 렐름 데이터·월드 생성·포털·매치 흐름·UI·디버그가 섞여 있고, 상태 변화마다 9렐름 전체를 재생성
