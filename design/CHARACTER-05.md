### A. Rio 키트 초안 (6버튼 구조)

| 입력 | 기술 | 설계 |
|---|---|---|
| J 중립/옆 | 마력 참격 3연 | 빠른 2타 + 마지막 짧은 검기(중거리 150px). 피해는 Frey보다 낮고 발동은 빠름 |
| J 위/공중 위 | 상승 베기 | 띄우기, 3단 점프와 이어지는 공중 추격 시작점 |
| J 아래/공중 아래 | 낙하 찌르기 | 공중에서 대각선 아래로 내리꽂기, 착지 후딜 큼 |
| K | 차원의 베기 | 입력 방향 200px 순간이동 + 지나간 자리에 베기 판정. 공중 1회. 복귀기 겸용 |
| L | 룬 보호막 | 0.5초 방패: 이 동안 받은 넉백을 흡수하고 끝날 때 전방 충격파로 되돌림. 쿨다운 3초. 빗나가면 무방비 |
| I | 인피니티 오버드라이브 | 보석 검 6자루가 주위를 돌다가 입력 방향으로 차례로 발사. 범위 정리·마무리용 |
| 고유 | 공중 3단 점프 | 기본 공중 점프 2회. Sky Step 카드와 중첩 시 상한 3회 |

- 기본 스탯 초안: HP 96, 공격 112, 방어 10, 속도 350, 점프 -740, 무게 0.94, 성장(레벨당) HP 4.5 / 공격 3.2 / 방어 1.0 / 속도 1.0.
- 약점: 낮은 HP·무게(링아웃에 약함), L을 읽히면 큰 손해, 지상전 화력이 Frey보다 낮음.
