## M1 — 한 판이 끝나고, 재미를 판단할 수 있는 게임

| 순서 | 작업 | 자동 완료 기준 |
|---:|---|---|
| 1 | 안정화: 투사체 수명, 오프스크린 AI 시간 버그, AI가 쓰는 공개 렐름 상태 API | lifetime 0.2/1.0/1.35초가 1 physics frame 이내로 맞음 |
| 2 | `MatchDirector` 웨이브 타임라인 (D2·D3) | 가상 시간 주입 테스트에서 120/150/210/240/360/420초 전이가 각각 정확히 1회 |
| 3 | 탈락·링아웃·붕괴 패널티·승리 (D1) | HP 0 후 10초가 지나도 부활 없음, 생존자 1명이 되는 프레임에 승자 신호 1회 |
| 4 | 렐름 재구성: 북유럽 이름, 1280×720 외곽 / 1920×1080 중앙, 포털 앵커, 좌우 블래스트 라인, 스폰 밀도, 몬스터 4마리 (D5·D6·D7) | 8명이 모서리 4곳에 2명씩, 경고 렐름마다 안정 렐름으로 가는 포털 ≥1 |
| 5 | 봇: 궁극기 사용 + 공통 쿨다운 30초, 렐름 크기 데이터화, 붕괴 회피 (D13) | 경고 후 봇 탈출 판단 시작 ≤0.7초, 쿨다운 위반 0 |
| 6 | 소울 성장 (D4) | 25/50/75에서 정확히 3회, 5초 자동 선택, 4번째 없음 |
| 7 | 최소 흐름: 시작·결과 오버레이, 재시작 (D14) | 재시작 10회 후 노드 수 기준선 복귀, 이전 매치 콜백 오류 0 |
| 8 | 검증 게이트 (Codex 분석 유닛) | 다수 시드 8봇 매치가 420초 이내 종료·승자 1명, 첫 PvP 적중 중앙값 ≤20초, 엔진 오류 0 |

사람이 판단할 것(자동 테스트 불가): 조작감, 타격 명료성, 첫 전투까지의 시간, 붕괴 공정성, 성장 선택의 의미, 중앙전 가독성. 첫 사람 검증은 6판, 4캐릭터 모두 사용, 항목별 5점 척도.
