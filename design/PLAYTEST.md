# M1 사람 플레이테스트 시트

자동 테스트와 Codex 봇 시뮬레이션으로는 판단할 수 없는 항목만 모았다
(출처: `reports/codex-plan-01`, `codex-tester-01`, `codex-analyst-01`의 "사람이 확인할 것").

## 준비

1. Godot 4.7로 `smash-nine-prototype/` 폴더를 연다 (또는 콘솔에서 `<godot> --path smash-nine-prototype`).
2. F5로 실행한다. 시작 화면에서 1–4로 캐릭터를 고른다. B는 봇끼리 싸우는 관전 모드다.
3. 조작: A/D 이동, W 점프, S 두 번 하강, Space 가드, J 공격(방향키로 변화), K/L 스킬, I 궁극기(30초 쿨다운), Q 포털, 1–3 소울 카드, F3 디버그, 결과 화면에서 R 재시작.

## 진행

6판을 한다. 4캐릭터를 모두 최소 한 번 쓴다. 판마다 아래 항목에 1–5점을 매기고 한 줄 메모를 남긴다.

| # | 항목 | 확인할 것 | 1판 | 2판 | 3판 | 4판 | 5판 | 6판 |
|---|---|---|---|---|---|---|---|---|
| 1 | 조작 반응 | 입력 → 몸이 반응 → 공격이 나가는 느낌. 무겁거나 미끄럽지 않은가 | | | | | | |
| 2 | 타격 명료성 | 맞았는지, 누가 밀려났는지 바로 보이는가 | | | | | | |
| 3 | 첫 전투까지의 시간 | 시작 후 지루하지 않게 싸움이 붙는가 (봇 기준 중앙값 약 5–8초) | | | | | | |
| 4 | 붕괴 공정성 | 2:00 경고 → 포털 탈출이 긴장감인가, 이동 노동인가. 30 피해가 억울한가 | | | | | | |
| 5 | 성장 선택의 의미 | 25/50/75 소울 카드가 전술을 바꾸는가, 숫자만 커지는가. 5초가 충분한가 | | | | | | |
| 6 | 중앙전 가독성 | 3:30 이후 중앙에서 여러 명이 싸울 때 화면을 읽을 수 있는가 | | | | | | |
| 7 | 탈락 후 경험 | 일찍 탈락했을 때 관전이 긴장감인가, 좌절인가 | | | | | | |
| 8 | 캐릭터 체감 밸런스 | 봇 기준 Frey가 강하고 Yuki가 약하다. 사람이 쓰면 어떤가 | | | | | | |

## 판정

- 1, 2, 4, 5번의 중앙값이 4 미만이면 아트나 콘텐츠보다 전투·밀도·붕괴 규칙을 먼저 다시 조정한다 (Codex 제안).
- 메모는 이 파일 아래에 날짜와 함께 적는다. 다음 작업 우선순위의 근거가 된다.
