# Image generation prompt set

Every prompt shared these constraints: polished hand-authored pixel art for a 128px-cell chibi platform brawler; genuinely transparent background; crisp clusters and hard pixel edges; generous padding; chronological grid order; no character, text, border, panel divider, watermark, blur, or cut edge.
