# 새 캐릭터 후보 (2026-11-26, 총괄)

사용자 요청(2026-11-26): "그 동안 Codex의 사용량을 좀 많이 소모 해야 하니 캐릭터를 더 만들어야 할 것 같다."

문장 끝의 표시: **[잼]** 은 잰 것, **[코드]** 는 코드·문서에서 읽은 것, **[추정]** 은 재지 않은 것이다.

## 한 문장 결론

**후보 여섯 명의 컨셉 그림을 Codex가 그리고, 사용자가 시안 월드컵에서 두 명을 고른다.** 고른 두 명은 Xion과 같은 순서로 만든다: 기술 → 몸 그림 → 기술 그림 → 고르기 → 게임에 넣기. 총괄 추천은 **Borok(중장갑 탱커)와 Raven(장거리 저격수)** 이다. 지금 여섯 명에게 없는 두 끝이기 때문이다. 하나는 가장 무거운 몸이고, 하나는 가장 먼 거리다.

- 컨셉을 직접 주고 싶으면(Xion 때처럼 "총잡이, 건카타, 여성, 이름 Xion") 언제든 주면 된다. 그쪽이 먼저다.
- 후보는 옛 기획서(`smash-nine/GAME_DESIGN_DOCUMENT.md` 3절, 20인 도감)에서 골랐다. 큰 틀만 지키고 세부는 새로 짠다(D22의 사용자 말).

| | 플레이 스타일 | 다른 여섯과 다른 점 | 한 줄 이야기 | 기술 스케치 | 체형(D22) |
|---|---|---|---|---|---|
| **Borok 보록** (추천) | 느리지만 잘 안 날아가는 탱커. 맞으면서 밀고 들어간다 | 넉백 저항과 아머가 무기다 | 스바르트알프하임 지하의 대장장이 왕 | 패시브 무쇠 몸(넉백이 덜 들어가는 대신 공중 점프 1회). J 해머 3연타, 셋째는 땅을 울려 발판 위의 적을 띄움. K 맞아도 멈추지 않는 돌진. L 모루를 놓고, 다시 치면 파편이 튐. U 발판 밑에서 용암이 솟음. I 화산의 제련소(주변이 용암 지대가 됨) | 남성 → 남·여 두 장 |

## 3. 진행 순서 (Xion 때와 같음)

1. **컨셉 그림 (지금, 「이미지/스프라이트 담당」, Codex 두 대).** 후보마다 메인 일러스트 1장과 게임 안 대기 1프레임을 그린다. 시안은 웹 빌드에 들어가지 않는 `art/bakeoff/`에 둔다. 여섯 명을 시안 월드컵 한 라운드로 올리면 15경기다.
2. **사용자가 고름.** 두 명과, 바꾸고 싶은 것(성별, 이름, 분위기)을 고른다. 마음에 드는 모습이 없으면 고른 캐릭터만 다른 모습 두세 개를 더 그린다.
3. **기술 (「캐릭터 스킬 담당」, Codex가 코드까지).** 고른 캐릭터의 기술을 위 스케치에서 시작해 표로 짜서 보이고, 임시 그림으로 게임에 넣는다.
4. **몸 그림 (「이미지/스프라이트 담당」).** 한 번에 한 캐릭터씩(D33): 기준 대기 프레임 → 걷기 → 점프·낙하·공격·방어·피격 → 승리·패배. 남성이면 두 체형을 그린다.
5. **기술 그림 (「캐릭터 스킬 담당」).** 동작 줄, 이펙트, 아이콘을 시안 월드컵으로 고른다.
