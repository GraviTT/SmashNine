## 측정

- head_scale.py는 자동 측정이고, face-manual.json은 별도의 얼굴 측정이다. 얼굴은 동일 배율의 4× 보드와 12× 픽셀 격자에서 눈 간격과 눈높이의 볼 폭을 확인했다.
- 앞머리·기울기로 눈높이 경계가 흐린 여성 4번 프레임은 수치 통과 집합에서 제외했다. 제외 후에도 각 행 5프레임이 0.96–1.04 범위다.
- 네 행 모두 border clear, 4px margin, spill 0, 이진 알파, detail 79 이상, 지정 발선, 한 얼굴·양손·검·양쪽 부츠를 확인했다.
- 3번 프레임이 타격 자세다. 스프라이트에는 궤적·잔상·마나 파동·룬·장벽을 그리지 않았다.

## 육안 판정

- low_sweep: 낮은 웅크림에서 짧게 지면을 베고 회복한다. 3·4번 검끝은 셀 안에 남는다.
- dimension_slash: 발도를 짧게 유지하다 3번에만 검을 뻗고, 긴 스플릿 자세 없이 제동한다.
- 여성·남성 attack: 기존 mana_combo 축소본이 아니라 검을 몸 앞에서 대각선으로 짧게 긋는 새 기본 공격이다.

## 아직 잘못된 점

- 후보만 만들었으므로 게임 시트 연결과 실제 hitbox/VFX 합성 화면은 검증하지 않았다.
- 여성 세 행의 4번 얼굴은 동작 기울기 때문에 눈 간격 수치 판정에서 제외했지만, 4× 육안으로는 동일 인물과 한 얼굴이 유지된다.

생성은 내장 ImageGen을 사용했고 사용·실패 원본과 두 앵커·기존 행 사본은 art/raw/rio-68/에 보존했다.
