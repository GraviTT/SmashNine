# CODEX-ART-43 결과

## 완료

새 일반형 Luna 앵커 `luna-idle-v3`와 카드의 일반형 동작 전부를 후보로 완성했다. 게임 파일은 수정하지 않았으며 후보는 `art/bakeoff/luna/`, 실제 사용한 built-in ImageGen 원본과 참조 이미지는 `art/raw/luna-43/`에만 두었다. Brave Luna 파일은 전혀 건드리지 않았다.

기존 `attack`은 128px 셀에서 앵커 머리 크기를 유지할 수 없어 카드 지시대로 192px 기술 후보 `star_side`로 전환했다.

## 눈으로 확인한 내용

- idle: 발을 고정한 작은 호흡 루프이며 지팡이, 얼굴, 부츠가 여섯 프레임 모두 온전하다.
- walk: 오른발 접지→다운→왼발 통과→왼발 접지→다운→오른발 통과가 읽히고 머리카락과 리본이 뒤따른다.
- jump/fall/hurt: 상승 시 무릎을 접고, 낙하 시 다리를 뻗고 머리카락이 위로 뜨며, 피격 시 눈을 감고 뒤로 젖혀져도 지팡이를 놓치지 않는다.
- star_side / star_up / star_down / star_comet: 준비·활성·후속·회수가 구분되며 궤적, 별꽃, 혜성 같은 게임 이펙트는 없다.
- shield: 지팡이를 몸 앞에 들어 올리고 무릎을 굽힌 채 버틴다. 기존 파란 방벽은 제거했다.
- moon_ring: 정면→측면→후면→반대 측면→정면의 한 바퀴 회전이 보이며 고리 이펙트는 없다.
- tumble: 몸을 웅크린 채 한 바퀴 후방 회전하고 얼굴이 여러 프레임에서 보이며, 전 프레임이 바닥에서 16px 이상 떠 있다.

## 아직 잘못되거나 제한된 점

- idle의 마지막 두 프레임은 자동 측정값이 각각 0.92지만, 6프레임 중앙값은 카드 하한인 0.96이고 공통 배율 원칙 때문에 프레임별 확대는 하지 않았다.
- `star_side`, `shield`, `star_up`, `star_comet`에는 자세 변화 때문에 일부 프레임 자동값이 1.06 또는 0.96으로 흔들리지만 행 중앙값은 0.96–1.04 범위다.
- fall, moon_ring의 측면·후면, tumble 회전 프레임은 머리 자동 탐지 점수가 낮거나 유효 프레임이 없어 수치와 육안 판단을 분리해 기록했다.
- shield의 유지 자세는 지팡이가 몸 앞 대각선으로 서 있으며, 완전히 수평으로 가로지르는 실루엣은 아니다.
- tumble의 중간 두 프레임은 역상 구간이 비슷해 회전 속도가 균일하기보다 중앙에서 잠깐 느려지는 인상이다.

후보와 보고서는 완료했지만 게임에는 반영하지 않았다. 모션 뷰어에서 사용자와 리드가 선택한 뒤에만 게임 시트로 조립할 수 있다.
