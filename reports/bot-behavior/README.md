# 봇 행동 원리 (2026-11-26 코드 기준)

사용자 요청(2026-10-09): "특정 캐릭터가 아닌 모든 기본적인 봇들의 행동 원리를 정리하고, 기본에서 뻗어나가 특정 캐릭터는 추가적으로 어떻게 행동하다 라는 것을 이미지로 정리."

- 봇 조절의 전체 과정과 다시 시작하는 법: `design/BOT_TUNING.md`.
- 근거 코드: `smash-nine-prototype/scripts/EnemyAI.gd` (봇 두뇌, 모든 캐릭터가 같은 파일을 씀). 캐릭터 차이는 같은 파일 안의 캐릭터별 표(거리 프로필, 복귀 기술, 궁극기 사거리), 캐릭터별 예외 몇 줄, 그리고 2026-11-24에 더한 "Kit moves" 구역(캐릭터 고유 기술을 쓰는 규칙)입니다. 일부 재입력은 캐릭터 스크립트 안에 있습니다(Rio의 검으로 순간이동·난무 베기, Xion의 도플갱어).
- 그림: `bot-behavior-tree.png`(Codex ART-19가 만든 위→아래 트리, 글자는 `tree.json` 그대로). 문구를 고친 뒤 `node reports/codex-art-19/render.js`로 다시 그립니다(`--all`이면 세 변형과 비교판까지). 이 문서는 그림보다 자세한 설명입니다.
- 거리는 게임 화면 px입니다. 공격 범위 1.5배(`GameScale.COMBAT`)와 맵 1.5배(`GameScale.WORLD`)를 반영한 값입니다.
- 키: J 기본 공격, K 기술 1, L 기술 2, U 기술 3(Nova·Rio·Xion), I 궁극기.

## 1. 매 프레임 하는 일 (순서대로)

1. 같은 렐름 상대가 휘두르기 시작했는지 확인합니다. 경직 중에도 확인해서, 경직 동안 시작된 공격을 나중에 새 공격으로 착각하지 않습니다.
2. 경직(맞는 중)이면 아무 입력도 하지 않습니다.
3. 타이머, 막힘, 표적 진전을 갱신합니다.
4. 낭떠러지로 떨어지는 중이면 **복귀** 상태로 들어갑니다(최우선).
5. 0.35~0.7초마다, 또는 표적이 사라지거나 1.1초 막히면 상태를 다시 고릅니다.
6. 가드 중이거나 가드 직전이면 가드가 이번 프레임을 차지합니다(이동 입력 0).
7. 상태별 행동을 만들고, 지형 위험(지진·분출·광선)을 피하도록 고친 뒤 입력합니다.

**상태 5가지:** 돌아다니기(표적 없음) · 쫓기(표적이 교전 거리 밖) · 교전(표적이 교전 거리 안) · 포털(렐름 이동) · 복귀(낙하 중 돌아오기).

**상태 고르는 순서:** 복귀가 끝나지 않았으면 복귀 유지 → 렐름 붕괴 경고 또는 저체력이면 포털 → 표적이 있으면 교전/쫓기 → 표적 없이 4초가 지났으면 5% 확률로 다른 렐름으로 → 아니면 돌아다니기.

## 2. 모든 봇 공통

### 판단

| 항목 | 규칙 |
| --- | --- |
| 표적 후보 | 같은 렐름의 살아 있는 선수(7,800px 안), 몬스터·소울 크리스털(2,250px 안). 덤불에 숨은 선수는 210px 안에서만 보입니다. |
| 표적 점수 | 거리 + 높이 차 × 0.12. 낮을수록 먼저. 몬스터 +480, 크리스털 +390(같은 거리면 크리스털이 몬스터보다 먼저). |
| 경기 단계 | 공격성: 탐색 0.3 → 모서리 붕괴 경고 0.45 → 수렴 0.7 → 중앙전·서든데스 1.0. 공격성이 낮으면 선수 점수에 (1 − 공격성) × 1,350을 더해 몬스터·크리스털을 더 고릅니다. 나를 때린 선수(8초 기억)는 예외입니다. |
| 선수 먼저 | 중앙전·서든데스이거나 4명 이하가 남으면 몬스터·크리스털을 모든 선수 뒤로 보냅니다. |
| 다른 층 표적 | 서 있는 발판이 138px 넘게 다르면 다른 층입니다. 다른 층 후보는 길을 찾아 보고, 길이 없으면 5초 동안 무시합니다. 길 찾기는 한 번에 3번까지만 하고, 그 뒤 후보는 확인 없이 고릅니다. 같은 층 후보는 확인 없이 고릅니다(틈 건너편도). |
| 표적 유지 | 한 번 고르면 1.6초 동안 유지합니다. |
| Rio의 분신 | 표적이 **사람이 조종하는 Rio**이고 그가 분신을 두면 분신마다 한 번, 60% 확률로 분신을 Rio로 착각합니다. 1.5초 동안(또는 분신이 사라질 때까지) 분신 쪽으로 가서 분신을 겨눠 공격합니다. 그 공격에 분신이 터집니다. 봇 Rio의 분신에는 속지 않습니다(결정 D56). 분신은 속지 않아도 터집니다: Rio가 분신을 두게 만든 그 휘두르기가 분신에 맞습니다. |
| 표적 포기 | 교전·쫓기 중 2.5초 동안 진전이 없으면 버리고 5초 무시합니다. 진전: 90px 이상 가까워짐, 상대가 8초 안에 나를 때렸거나 내가 3초 안에 상대를 때림, 같은 층이고 그쪽 길이 열림(막힌 길이어도 2.5초 안에 공격했으면 진전). |

### 이동

| 항목 | 규칙 |
| --- | --- |
| 쫓기 | 같은 높이(138px 안)면 표적에게 곧장 갑니다. 다른 층이면 렐름의 내비게이션 점으로 A* 길찾기를 합니다. |
| 길 연결 | 같은 층 705px 안, 위로 한 번 점프 높이 187.5px까지, 아래로 540px까지(옆으로 129~705px). 서로 다른 발판 사이 틈은 점프 172px·낙하 300px까지만 씁니다. 위 발판으로의 점프는 그 발판 가장자리 165px 안에서만 시작합니다. |
| 발 앞 확인 | 앞에 바닥이 있으면 걷고, 없으면 내려가도 되는 길이면 내려가고, 177px·240px 앞에 착지할 곳이 있으면 점프합니다. 셋 다 아니면 멈추고 그 방향을 0.65초 동안 막힌 길로 기억하며 다시 계획합니다. |
| 막힘 | 걷는데 0.45초 동안 20px도 못 가면 점프, 1.1초면 다시 계획합니다. |
| 공중 점프 | 오르는 중 공중 점프는 2번 이상 남았을 때만, 바닥 위에서만 씁니다. 마지막 1번은 복귀용입니다. |
| 포털 | 렐름 붕괴 경고면 가장 가까운 포털로(경고 렐름 쪽은 피함). 포털 이동 뒤 8초는 그 렐름에 머뭅니다. |
| 저체력 후퇴 | 중앙전 전(공격성 0.8 미만)이고 3명 이상 살아 있고 체력 30% 미만이면, 아무도 없는 안정 렐름으로 갑니다. 그런 렐름이 없으면 그 자리에서 4초 동안 물러섭니다. 10초에 한 번만 판단합니다. |
| 화면 밖 렐름 | 화면에 안 보이는 렐름의 봇은 3~7초마다 렐름 이동을 따로 판단합니다. 붕괴 경고면 안정 렐름으로 탈출, 상대가 있으면 92% 머묾, 아니면 30% 확률로 다른 상대가 있는 렐름 쪽으로, 5% 확률로 아무 안전한 렐름으로 갑니다. |
| 지형 위험 | 경고마다 80% 확률로만 반응합니다. 지진이 0.35초 안에 떨어지면 점프하고, 분출·광선 기둥(좌우 40px 여유) 안이면 공격을 멈추고 비켜 섭니다. |

### 생존

| 항목 | 규칙 |
