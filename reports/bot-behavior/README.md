# 봇 행동 원리 (2026-10-09 코드 기준)

사용자 요청(2026-10-09): "특정 캐릭터가 아닌 모든 기본적인 봇들의 행동 원리를 정리하고, 기본에서 뻗어나가 특정 캐릭터는 추가적으로 어떻게 행동하다 라는 것을 이미지로 정리."

- 근거 코드: `smash-nine-prototype/scripts/EnemyAI.gd` (봇 두뇌, 모든 캐릭터가 같은 파일을 씀). 캐릭터 차이는 같은 파일 안의 캐릭터별 표(거리 프로필, 복귀 기술, 궁극기 사거리)와 캐릭터별 예외 몇 줄뿐입니다.
- 그림: `bot-behavior-tree.png`(Codex ART-19가 만든 위→아래 트리, 글자는 `tree.json` 그대로). 문구를 고친 뒤 `node reports/codex-art-19/render.js`로 다시 그립니다(`--all`이면 세 변형과 비교판까지). 이 문서는 그림보다 자세한 설명입니다.
- 거리는 게임 화면 px입니다. 공격 범위 1.5배(`GameScale.COMBAT`)와 맵 1.5배(`GameScale.WORLD`)를 반영한 값입니다.
- 키: J 기본 공격, K 기술 1, L 기술 2, I 궁극기.

## 1. 매 프레임 하는 일 (순서대로)

1. 같은 렐름 상대가 휘두르기 시작했는지 확인합니다. 경직 중에도 확인해서, 경직 동안 시작된 공격을 나중에 새 공격으로 착각하지 않습니다.
2. 경직(맞는 중)이면 아무 입력도 하지 않습니다.
3. 타이머, 막힘, 표적 진전을 갱신합니다.
4. 낭떠러지로 떨어지는 중이면 **복귀** 상태로 들어갑니다(최우선).
5. 0.35~0.7초마다, 또는 표적이 사라지거나 1.1초 막히면 상태를 다시 고릅니다.
6. 가드 중이거나 가드 직전이면 가드가 이번 프레임을 차지합니다(이동 입력 0).
7. 상태별 행동을 만들고, 지형 위험(지진·분출·광선)을 피하도록 고친 뒤 입력합니다.

**상태 5가지:** 돌아다니기(표적 없음) · 쫓기(표적이 교전 거리 밖) · 교전(표적이 교전 거리 안) · 포털(렐름 이동) · 복귀(낙하 중 돌아오기).

**상태 고르는 순서:** 복귀가 끝나지 않았으면 복귀 유지 → 렐름 붕괴 경고 또는 저체력이면 포털 → 표적이 있으면 교전/쫓기 → 표적 없이 4초가 지났으면 5% 확률로 다른 렐름으로 → 아니면 돌아다니기.
