# CODEX-VFX-09 B — 방향을 따라 남는 별가루

완료: 기존 12종을 이어 받아 **151프레임 전부를 실제 게임 스프라이트와 합성한 1배·4배 이미지로 직접 검수**했다. Luna 발걸음·지상 점프의 검은 끝 잔상과 Brave 어퍼컷의 반대편 배치를 수정하고 이 3종만 다시 구웠다. 나머지 9종 PNG는 유지했다. 후보 제작이며 게임에는 연결하지 않았다. A 폴더·A 파일은 열지 않았다.

## 그림과 수정

- Luna 발걸음: 앞발 뒤쪽으로 낮게 흐르는 분홍 먼지·금빛 별. 지상 점프: 양옆으로 밀려나는 별가루. 이 두 보통 섞기 효과의 별을 불투명한 어두운 RGB로 감쇠하던 문제를 **색을 유지한 투명도 감쇠**로 고쳤다. 공중 점프는 발밑에서 두 갈래로 벌어져 아래로 떨어지는 별빛을 유지했다.
- Brave J: 잽 → 보디 킥 → 회전 킥 순으로 넓어지는 끊어진 선·별조각. 어퍼컷은 위로, 낮은 후리기는 발 높이로, 비행 킥은 앞으로, 급강하는 아래로 흐른다. 어퍼컷은 머리 반대편에 떨어져 보이던 여운을 주먹 쪽으로 옮겼다. 각도는 그림에 포함하고 중력은 화면 아래 방향, 바닥 반동은 없다.
- 적중 여운: 기존 적중 불꽃 바깥에서 앞쪽으로 흘러내리는 별조각. 큰 적중은 더 넓고 오래 남으며 중심 섬광을 추가하지 않는다.
- 검수 합성도 수정했다. 192px 동작 칸의 발 기준을 잘못된 y=184에서 게임의 **y=152**로, 기존 참격의 2배 원본 보정을 `Vfx.size_ratio`에 맞게 수정했다. 참격 두께 0.62, 36fps·6장, 적중 불꽃 44fps·4장, 채택된 동작 속도, 현재 3장 점프 그림을 반영했다. 공중 기술 후에는 낙하 그림을 쓴다.

## VFX-08 기준 측정

## 확인 결과

- `node reports/codex-vfx-09-b/audit.mjs`: 12종 모두 PASS. 첫 프레임 공백 0, 1px 테두리 침범 0, 40px 확장 캔버스에서 잘림 0, 반복 렌더 차이 0, 저장 PNG와 모듈 재렌더의 차이 0.
- 더하기 합성 10종: 알파 0/255, max(R,G,B)<40 제거. 보통 섞기 2종: 투명도 사용, 어두운 불투명 별가루 검사 통과. 모든 일회성 효과는 종료 시 완전히 빈다. 마지막 저장 프레임 밝기는 최대의 0~6.94%다. 일부 마지막 칸은 이미 빈 감쇠 끝이다.
- Brave 9종의 고정 보호 구역에 후보 픽셀 0: 몸 중심 기준 머리 x=-36..36/y=-98..-22, 몸통 x=-22..22/y=-21..24. 기존 참격·적중 불꽃의 가림은 이 수치에 포함하지 않는다. 실제 합성에서도 새 여운이 얼굴·몸 중심을 덮지 않는지 확인했다.
- [measurements.json](measurements.json)에 프레임별 픽셀·밝기·경계, 마지막 표시 프레임, 앵커, PNG 해시와 재현 결과를 남겼다. `audit.mjs`에는 검은 잔상과 저장 파일 불일치를 다시 잡는 검사를 추가했다.

## 시각적 확인

[board.png](board.png)는 12종의 실제 자산 합성 1배와 4배 확대다. [qa/](qa/)에는 전 프레임의 4배 접촉판 47장과 1배 접촉판 12장이 있다. 프레임 번호·시각을 표시했고 재검수 때 같은 파일을 덮어썼다.

**실행 화면 녹화가 아닌 벤치 합성**이다. 그림의 기준점을 고정해 방향·감쇠·몸 겹침을 검사했으며, 실제 이동 궤적·충돌·히트스톱·연속 적중은 재현하지 않았다. 기존 참격과 적중 불꽃은 각자의 게임 재생 시간 동안 함께 보인다. Brave 잽 3연타는 각각 따로 검사한 것이며 연속 콤보의 누적 겹침 검사는 아니다.

## 남은 작업 / 다음 권장 단계

- v2 강도가 적절한지, 어퍼컷의 얼굴을 피한 측면 여운과 급강하의 긴 꼬리가 좋은지는 시안 월드컵에서 판단한다.
- 리드가 후보를 연결한 뒤 걷기 4·8번째의 +17/+18px 생성, 좌우 반전, 지상·공중 어퍼컷, 적중당 1회, 은신/F2, 실제 이동 중 겹침을 확인해야 한다. 이 실행 검증은 하지 않았다.
- 8인 경기 0.85배 카메라·웹 성능과 실제 게임 녹화도 미검증이다. 판정·피해·시간·히트스톱 및 제품 코드는 바꾸지 않았다.
- `commit.ps1`은 **이번 VFX-09 B 파일과 카드만** 문자열 배열로 명시했다. Windows PowerShell 5.1의 JSON 배열 변환을 쓰지 않는다. 스크립트 작성·구문 검증까지 했으며 실제 커밋은 실행하지 않았다.

## 재현

저장소 루트에서 실행한다. Node 24, 기존 pinned pixelfx 사본을 읽기 전용으로 사용하며 설치는 필요 없다. Luna의 기존 `bake.mjs`는 VFX-08용이므로 이 카드에서는 `bake-09.mjs`를 쓴다.

```text
node art/bakeoff/effects/pixelfx/luna_brave/b/bake.mjs
node reports/codex-vfx-09-b/audit.mjs

```
