# CODEX-ART-19 결과 보고

## 선택 결과

최종 이미지는 **C안(위→아래 계층형 트리)**을 선택했다.

- 위쪽의 `기본 봇`에서 판단·이동·전투·생존 네 기둥이 바로 갈라져 공통 원리를 먼저 읽을 수 있다.
- 같은 루트에서 `캐릭터별 추가 행동`이 아래로 이어져, 캐릭터 카드가 별도 표가 아니라 **공통 원리에 더해지는 추가 분기**로 읽힌다.
- 4개 공통 기둥과 5개 캐릭터 카드가 고정 열에 놓여 연결선 교차가 없고, 50% 축소에서도 가장 안정적으로 훑을 수 있었다.

최종 파일은 `reports/bot-behavior/bot-behavior-tree.png`이며 `variant-c.png`와 SHA-256이 같다.

## 완성한 변형

- `variant-a.png`: 중앙 루트에서 네 사분면으로 뻗는 방사형 마인드맵. 전체 관계를 한눈에 보기 좋지만 시선이 좌우·상하로 왕복한다.
- `variant-b.png`: 왼쪽에서 오른쪽으로 읽는 열 기반 트리. 단계 관계는 명확하지만 긴 가로 띠에서 세부 문장이 더 조밀하다.
- `variant-c.png`: 위→아래 계층형 트리. 공통 원리와 캐릭터 추가 분기를 가장 빠르게 구분할 수 있어 최종 선택했다.
- `contact.png`: 세 변형의 25% 전체 보기와 각 변형의 가장 조밀한 영역 100% 크롭.
- `chosen-50.png`, `chosen-100-crop.png`: 최종 C안의 50% 확인본과 100% 조밀 영역 확인본.

## 측정 검사

자동 검사 결과는 `checks.json`에 저장했다.

- PNG 크기: A/B/C 및 최종 이미지 모두 **3840×2800 px**.
- 표시 대상 문자열: 각 변형 **기대 102 / 실제 102**, 누락 0, 추가 0. 제목·부제·루트·그룹·가지·잎·캐릭터 이름/역할/프로필·푸터를 다중집합으로 비교했다.
- 배치 경계 상자: 각 변형 박스 겹침 0, 텍스트 줄 겹침 0, 텍스트의 부모 박스 이탈 0, 캔버스 밖 잘림 0.
- 글자 크기: 제목 76px, 그룹/캐릭터 분기 44px 굵게, 가지 34px 굵게, 잎 28px. 렌더 뒤 글자를 축소하지 않았다.
- 대비비 최솟값: **6.4009:1**. WCAG 4.5:1 기준보다 높다. 주요 값은 어두운 글자/배경 14.6124:1, 흰 글자/어두운 상자 15.5177:1, 어두운 글자/가장 옅은 분기색 12.8522:1이다.

## 눈으로 확인한 결과

- 100%: Malgun Gothic 획과 숫자·단위가 선명하고, 가장 조밀한 전투 영역에서도 글줄과 연결선이 겹치지 않는다. 얼굴 이미지는 최근접 보간으로 가장자리가 흐려지지 않았다.
- 50%(1920×1400): 잎 문구까지 읽을 수 있었고, 제목→기본 봇→4개 공통 기둥→캐릭터 추가 분기 순서가 유지됐다.
- A안은 마인드맵 느낌이 가장 강하고 B안은 트리 구조가 직접적이지만, 실제 설명용으로는 C안의 고정 열과 짧은 시선 이동이 가장 읽기 좋다고 판단했다.

## 다시 렌더링

저장소 루트에서 다음 한 명령을 실행한다.

```powershell
powershell -ExecutionPolicy Bypass -File reports/codex-art-19/render.ps1
```

이 명령은 `tree.json`을 다시 읽어 A/B/C SVG·HTML·PNG, 접촉 시트, 50%·100% 확인본, `checks.json`, 최종 `bot-behavior-tree.png`를 재생성한다. 외부 패키지나 다운로드는 필요 없다.

현재 환경에서는 `.git` 쓰기가 허용되지 않아 커밋하지 않았다. `commit.ps1`은 카드의 두 쓰기 경로만 스테이징하고 `Co-Authored-By: Codex <noreply@openai.com>`로 끝나는 커밋 메시지를 사용한다.

## 사람이 최종 판단할 부분

- C안의 많은 세로 여백을 편안한 설명 자료로 볼지, 더 압축된 정보 밀도를 선호할지.
- A안의 마인드맵 분위기와 C안의 문서형 가독성 중 제품 커뮤니케이션 톤에 더 맞는 쪽.
- 캐릭터 카드를 현재처럼 동일 높이로 맞춘 균형감과, 잎 수에 따라 카드 높이를 달리하는 밀도감 중 어느 쪽을 선호할지.
