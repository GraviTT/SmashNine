# CODEX-ART-69 · 8폼 패배 모션 결과

카드 순서대로 8폼의 `defeat` 후보를 모두 만들었다. 각 후보는 192px 셀 6장, 10fps, 한 번 재생이며 마지막 장은 바닥에 누운 자세다. 내장 ImageGen에 각 폼의 채택 대기를 Image 1로 넣었고, 한 동작을 3×2 한 장으로 생성한 뒤 D35 경로로 정규화했다. `smash-nine-prototype/`은 바꾸지 않았다.

## 육안 판정

- 모든 프레임을 4배 판에서 확인했다. 반동 → 비틀거림 → 무릎 붕괴 → 낙하 → 작은 충돌 → 정지 흐름이 8폼 모두 읽힌다.
- 프레임마다 얼굴 하나, 양손·양발, 해당 무기(Frey 검·방패, Luna 지팡이, Rio 검)를 확인했다. 복제된 팔다리·무기, 이펙트, 글자는 없다.
- 5·6번은 모두 바닥선 y=152에 닿고, 6번은 눈을 감고 정지한다. 전 프레임 이진 알파이며 초록 번짐은 0이다.
- Rio 남 원본의 고립된 청록 점 5px은 `--min-component 21`로 제거했고, 제거 뒤 전 프레임을 다시 확인했다.
- Rio 남 2차 수정에서는 1–4번을 픽셀 단위로 그대로 보존했다. 5번은 4번에서 이어져 머리가 왼쪽인 등 착지와 작은 바운스로, 6번은 같은 방향으로 눈을 감고 바로 누운 자세와 곁에 놓인 검으로 교체했다.

## 아직 잘못된 점

- 수치·4배 검수에서 전달을 막는 문제는 없다.
- 패배 연출은 후보만 만들었다. 모션 뷰어에서 사용자가 채택하기 전이며 게임 연결·Godot 실행은 카드 범위 밖이다.

각 폼의 4배 앵커 비교판은 `frey-defeat.png`부터 `rio_female-defeat.png`까지의 파일이다.
