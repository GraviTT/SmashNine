## 1. 소리 (소리 뷰어 DB에 기록함)

[소리 뷰어](https://claude.ai/artifact/BWneucCv1GHme5JX7fmUuW) DB `sound_picks`에 13개 문서를 썼다. 사용자가 고른 것은 없었다. 메모는 모두 "추천대로 결정(Claude, 10-29)"으로 시작한다.

| 대상 | 스타일 | 이유 (이미지/스프라이트 세션) |
|---|---|---|
| 효과음 전체 (`style`) | **c** | 시험 12종 스펙트럼에서 c만 저음이 묵직하다(30–120Hz 중앙값 5.0%, 무거운 타격 72%). 고음은 1.4%로 a(4.0%)보다 덜 날카롭다. 난투 타격감과 세밀한 픽셀 그림체에 8비트 a보다 맞는다(추정). 세 스타일의 음량은 같다 |
| `ui_move`, `ui_select`, `ui_cancel`, `story_text`, `story_advance` | **b** | 자주 반복되고 메뉴·대사 음악(b) 아래에서 들린다. 고음이 가장 적다. 시험 `ui_select` 중심 주파수는 b 982Hz, c 1251Hz, a 1898Hz다(추정) |
| `victory`, `results` | **b** | 결과·엔딩 음악(b)으로 바로 이어지므로 같은 FM 계열로 맞춘다(추정) |
| `music_title` | **b** | FM 종 선율과 따뜻한 패드. 반복 이음새 차가 세 안 중 가장 작다(0.00043 FS) |
| `music_battle` | **b** | 효과음 c의 순간 잡음·저음과 덜 겹치는 둥근 FM 전투곡이다(추정: c 전투곡의 겹친 북이 타격음을 가릴 수 있다). 다섯 곡을 한 계열로 맞춘다 |
| `music_select` | **b** | 4kHz 이상 0.08%로 가장 부드럽고(a 1.12%, c 0.71%), 이음새 차도 가장 작다 |
| `music_story` | **b** | 대사 아래에 깔리는 곡이고, 나머지 곡과 한 계열로 맞춘다. 세 안 모두 이음새 검사를 통과했다 |
| `music_results` | **b** | 4kHz 이상 0.04%로 가장 부드럽고, "팡파르 뒤 따뜻한 패드"라는 의도와 맞는다 |

- **한계:** 직접 들어 보고 정한 것이 아니다. 파형·스펙트럼·음량·이음새 측정(AUD-01/01a/02/02a)을 근거로 했다. 담당 세션은 경고음(`collapse_warning`, `monster_windup`)과 메뉴음만이라도 사용자가 들어 보기를 권했다.
- **적용할 때:** b/c 음악은 스테레오라 WAV 합계가 약 31MB다(a는 16MB). OGG로 바꿔 넣으면 웹 용량은 문제없다. 게임의 소리 로더는 `.ogg`를 먼저 읽는다. 소리 연결 코드(SYS-05·08)는 이미 들어가 있어서 파일만 넣으면 된다.

## 2. 스토리 그림 (SART-01~04, `after-cp/story-mode`)

스토리 모드 세션은 유닛 추천을 그대로 쓰기로 했다. 바꾼 것은 ⑤ 타이틀 카드에 밝기 보정 조건을 붙인 것 하나다.

| 항목 | 결정 | 이유 |
|---|---|---|
| 장면 그림 ⑤ 숲 | `cg_forest-v1` | 넓은 구도라 섬이 무너지는 모습과 높이가 다른 수정 3개가 잘 보인다 |
| 장면 그림 ⑦ 멧돼지 | `cg_beast-v3` | 땅을 긁는 돌진 직전의 옆모습으로, 게임 속 멧돼지와 같은 방향이다. v4는 정면이라 코가 어색하다 |
| 장면 그림 ⑨ 심장 | `cg_heart-v1` | 불기둥 5개가 또렷하고, ⑨ 타이틀 카드 v3와 같은 장면으로 이어진다 |
| 타이틀 카드 ①~④·⑥~⑨ | ①v2 ②v4 ③v3 ④v2 ⑥v2 ⑦v5 ⑧v1 ⑨v3 | 랜드마크가 가장 또렷하고, 같은 장소의 장면 그림과 톤이 맞는다 |
| 타이틀 카드 ⑤ | v3, **적용할 때 밝기 ×0.75·채도 ×0.9** | 세 안 모두 낮 하늘이라 혼자 밝다(0.41, 세트 평균 0.31). 보정하면 0.30이 되고 붕괴 빛도 살아 있다 |
| 부적 수정 | `cg_root-v5` (지금 `cg_root` 교체) | 과녁처럼 잘못 읽히던 문제가 사라진다. 바뀐 곳은 종이뿐이고 파일 이름이 같아 코드 변경도 없다. 큰 종이의 붉은 획이 'P'처럼 보일 여지는 남는다 |
| 시작 카드 틀 | `start_card_frame-v1` 사용 | 이미 들어간 대화 상자 틀과 장식도 색 5개도 같아서, 시작 카드가 대사 화면과 한 벌로 보인다. 가운데가 투명하니 어두운 바탕은 남긴다 |
| 지도 장식 | 길 v1, 다음 표식 v2, 완료 인장 v1, 잠금 인장 v1 | 길은 칸 사이 틈에서 차분하게 이어진다. 표식 v2는 반복 이음이 가장 고르다. 인장 v1은 40px에서 가장 빨리 읽힌다 |
| ⑨ 그림자 소멸 효과 | `shadow_dissolve-v1` | 기존 그림자 오라와 같은 가는 연무다 |

**적용할 때 필요한 것**
- 장면 그림을 `StoryCatalog._dialogue`의 ⑤·⑦·⑨ 시작 해설에 붙인다. `test_story_presentation`의 기대값도 고친다.
- 타이틀 카드와 시작 카드 틀을 `StoryScreens.show_stage_card`에 넣는다(`NinePatchRect`, 여백 24).
- 지도 장식을 `show_story_map`에 넣는다.
- ⑨ 그림자가 쓰러질 때 소멸 시트를 재생한다. 발 기준이 기존 오라와 다르므로 맞춰서 놓는다.
- 그림은 손실 압축으로 가져온다. 웹 빌드가 약 +3MB 늘어난다.
