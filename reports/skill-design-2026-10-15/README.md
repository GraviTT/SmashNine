## 2. 설계 원칙

1. **핵심 규칙은 캐릭터마다 하나.** 그 캐릭터만 하는 일이 있어야 합니다(Frey 방패, Yuki 덫, Luna 변신, Nova 속도, Rio 공중 체류).
2. **이기는 방식을 나눕니다.** 이 게임은 HP가 0이 되면 탈락하고, 링아웃은 HP 피해입니다. 그래서 상대를 이기는 길이 셋입니다.
   - 링아웃: Frey는 밀어서, Nova는 날려서
   - HP 직접 피해: Rio는 다단으로, Luna는 광역으로
   - 통제: Yuki가 묶으면 자기나 다른 사람이 처리
3. **배틀로얄 안의 자리가 다릅니다.** 언제, 어디서 강한지가 캐릭터마다 다릅니다.
   - Frey: 좁은 자리
   - Yuki: 길목, 후반
   - Luna: 난전
   - Nova: 넓은 렐름, 추격
   - Rio: 남의 싸움
4. **상성이 있습니다.** 누구에게나 강한 캐릭터는 없고, 약점은 실력으로 메울 수 있어야 합니다(D31 7번째 기준).
5. **그림을 아낍니다.** 다섯 명 모두 동작 줄을 막 다시 그렸으므로, 지금 줄을 최대한 다시 씁니다. 새로 그릴 것은 줄 1~2개와 이펙트 몇 장입니다(4절 각 캐릭터의 "비용").

## 4. 캐릭터별 제안

### Frey — 방패 전선 (Vanguard)

**정체성:** 버티고 밀어낸다. 공중을 쫓아다니는 대신 땅을 차지하고, 한 번의 상승(L)으로 띄워 내리칩니다. 그림 속 Frey는 이미 검과 방패를 듭니다(`frey_illustration.png`, `shield` 줄). GDD 원안에도 "수호의 방패"가 있었습니다.

| 입력 | 지금 | 제안 | 이유 |
| --- | --- | --- | --- |
| J 1·2타 | 검 연계 | 유지 | |
| J 3타 | 넓게 베어 날림 | **방패 밀치기:** 낮고 수평으로 미는 넉백 | 밀어내기가 Frey의 이기는 방식 |
| 방향 J | 대공·내려 베기·공중 옆 | 유지 | |
| K | 8방향 돌진 찌르기 | **방패 돌진:** 좌우로만 돌진합니다. 그동안 정면 공격과 투사체를 막고, 맞은 상대를 밀고 가다 끝에 밀쳐냅니다. | 네 명이 같은 8방향 K를 씁니다. Frey만 정면을 막으며 들어갑니다. |
| L + 재입력 | 상승 가르기 → 강스파이크 | 유지 | Frey의 유일한 공중 한 방이자 위쪽 복귀 수단(상승 속도 -560) |
| I | 좌우 충격파 + 기절 | 유지 | |
| 상시 | 발키리의 추격(공중 이동 +15%) | **불굴:** J 3타·K·L 동작 중에는 약한 공격에 경직·넉백이 없습니다(피해는 받음). | 전선은 맞으면서 버텨야 합니다. 공중 추격은 Rio·Nova가 할 일입니다. |

- **역할:**
  - 전투: 정면 견제를 방패로 뚫고 들어가 발판 끝으로 밉니다.
  - 매치: 포털 앞이나 중앙 발판처럼 좁은 자리를 지킵니다. 사람이 몰리는 후반에 강합니다.
- **약점:** 정면만 막아서 위·뒤로 오는 Rio·Nova에 약합니다. 공중 기동은 점프 1회와 L뿐이고, 느립니다.
- **상대의 대응:** 방패 돌진을 뛰어넘어 뒤를 칩니다. 불굴은 "약한 공격"만 버티므로 강한 기술로 끊습니다.
- **비용:**
  - 그림: 새 동작 줄 1개(방패 돌진). `frey_k` 이펙트를 다시 그립니다. 불굴 표시는 공용 아머 번쩍임을 다시 씁니다.
  - 봇: 돌진 조준을 좌우로 바꿉니다. 복귀는 K 좌우와 L 위로 합니다.
  - 지금 `frey_pursuit_mark.png`는 더 쓰지 않게 됩니다.
- **대안:**
  - (나) K는 그대로 두고 3타만 방패 밀치기로 바꿉니다.
  - (다) 패시브는 추격으로 유지합니다.
- **주의:** Frey 밸런스는 2026-10-06부터 보류 중입니다. 이번 변경은 수치가 아니라 구성이지만, 강함도 바뀝니다.

### Yuki — 결계사 (Zone Controller)

**정체성:** 미리 깔고 묶는다. 지금 봉인부는 L을 누르기 전까지 아무 일도 하지 않습니다. 깔아 두기만 해도 길이 막혀야 컨트롤러입니다. GDD의 컨트롤러 정의도 "공중 안전 복귀 경로를 감쇠·차단"입니다.

| 입력 | 지금 | 제안 | 이유 |
| --- | --- | --- | --- |
| J 직선 부적 | 견제 | 유지. 선택: 자기 봉인부에 맞히면 그 봉인부가 바로 작게 터짐 | 원격 기폭으로 J와 K가 이어짐 |
| 위 J·공중 아래 J | 대공 부적, 낙하부 | 유지 | |
| 아래 J | 퇴마 파동(근접 밀어내기) | 유지 | 근접 탈출 수단 |
| K | 봉인부 설치(L 전엔 무반응) | **덫:** 적이 반경에 들어오면 이동이 느려지고(예: −40%) 부적이 빛나 위치가 드러납니다. 최대 2개, 5초, 한 대에 찢어짐은 그대로입니다. | 깔아 두는 것만으로 착지·복귀 경로가 막힙니다. |
| L | 결계 해방 | 유지 | 덫에 걸린 상대를 터뜨리는 마무리 |
| I | 사방봉진(끌어당김 + 파동) | **가두기:** 경계가 벽이 되어 안의 적이 2.35초 동안 나가지 못합니다. 파동과 마지막 폭발은 그대로입니다. | 끌어당기기는 Nova 궁극기와 겹칩니다. 가두기는 봉인술사만 합니다. |
| 상시 | 없음 | 덫 자체가 상시 규칙 | |

- **역할:**
  - 전투: 착지와 복귀 경로에 덫을 깔아 묶습니다.
  - 매치: 포털, 통로, 발판 연결 지점을 봉쇄합니다. 성장률이 높은 후반형이라 좁아지는 후반에 강합니다.
- **약점:** 근접이 약하고 초반 체력이 낮습니다. 설치에 시간이 들고 봉인부가 부서집니다.
- **상대의 대응:** 봉인부를 먼저 칩니다(한 대에 찢어짐). Frey처럼 정면으로 밀고 들어옵니다. 경계가 생기기 전 예고 0.7초 안에 빠져나갑니다.
- **비용:** 동작 줄은 그대로 씁니다. 이펙트는 덫 발동 표시 1장이고, 가두기 경계는 사방봉진 그림을 다시 쓸 수 있습니다. 봇은 감속 지대 인식과 Yuki의 K 설치 위치를 맞춥니다.

### Luna — 별빛 변신 (Switch)

**정체성:** 이미 로스터에서 가장 독자적입니다(Codex 5점). 큰 변경은 없습니다.

| 입력 | 제안 | 이유 |
| --- | --- | --- |
| 평상시·Brave 기술 전부 | 유지 | |
| 별빛 충전 | **다수 적중 보너스:** 한 번에 두 명 이상 맞히면 별 2개 | 여럿이 싸우는 곳에 끼어들수록 변신이 빨리 옵니다. 배틀로얄 안의 자리가 생깁니다. |

- **역할:**
  - 전투: 평상시에는 중거리 광역, 변신하면 6초 근접 폭발입니다.
  - 매치: 세 명 이상 싸우는 난전에 끼어듭니다.
- **약점:** 가볍고, 평상시에는 복귀 수단이 없고 근접이 약합니다. 변신 시간을 낭비하면 손해입니다.
- **비용:** 코드만 바뀝니다.
- **남는 겹침:** Brave의 낮은 후리기와 급강하 킥이 Rio·Nova와 비슷합니다. 변신은 6초 한정이라 그대로 둡니다.

### Nova — 속도 사냥꾼 (Momentum Hunter)

**정체성:** 속도를 힘으로 바꾼다. 규칙은 이미 독자적이지만, 위 J가 남들과 같은 "띄우고 따라 오르기"입니다. 중력 히어로답게 바꿉니다(GDD 원안 "제로 그라비티").

| 입력 | 지금 | 제안 | 이유 |
| --- | --- | --- | --- |
| J 옆·공중 J | 속도 → 타격 | 유지 | |
| 위 J | 벡터 어퍼컷(같이 떠오름) | **무중력:** 맞은 상대가 0.6초 동안 중력을 잃고, 맞은 방향으로 천천히 떠갑니다. 행동은 할 수 있지만 떨어지지 않습니다. Nova 자신은 떠오르지 않습니다. | 띄우는 위 J는 Frey·Rio·Brave에도 있습니다. 상대의 중력을 바꾸는 것은 Nova만 합니다. |
| 아래 J·메테오 킥 | 원형 충격 | 유지 | 착지 충격이 속도에 비례하는 것은 Nova만의 특징 |
| K·L·I | 가속, 제동, 투석 | 유지 | 이미 다름 |

- **역할:**
  - 전투: 고속 충돌로 크게 날립니다. 띄운 상대를 무중력으로 붙잡아 두고 속도를 붙여 다시 칩니다.
  - 매치: 넓은 외곽 렐름을 누비고, 렐름 사이를 이동하며 도망치는 저체력 상대를 쫓습니다.
- **약점:** 멈추면 약하고, 좁은 곳(후반 중앙)에서는 속도를 내기 어렵습니다. K 가속 중에는 무방비입니다.
- **비용:** 동작 줄은 `vector_upper`를 다시 씁니다. 이펙트는 상대 몸에 씌우는 무중력 거품 1장입니다. 봇은 위 J 뒤 공중 추격 규칙을 맞춥니다.

### Rio — 공중 어쌔신 (Aerial Assassin)

**정체성:** 들어가서 끝내고 빠진다. Rio는 지금 J 구성이 Frey와 거의 같습니다. 그래서 Rio의 개성은 두 가지로 냅니다.
- **땅에 내려오지 않는 공중 체류**
- **밀어내지 않고 HP를 깎는 다단 베기**

D21에서 고른 K, L, I, 2회 공중 점프는 그대로 둡니다.

| 입력 | 지금 | 제안 | 이유 |
| --- | --- | --- | --- |

- **역할:**
  - 전투: 공중 결투와 받아치기로 싸웁니다.

- **약점:** 가벼워서 링아웃에 약합니다. 밀어내지 못해 링아웃을 만들 수 없고 HP로만 이깁니다. 1:1에서는 제3자 보너스가 켜지지 않습니다.
- **비용:** 그림은 `plunge` 줄(찌르기)과 `jump` 줄(튕김)을 다시 씁니다. 제3자 표시는 작은 이펙트 1장이고, 없어도 됩니다. 코드에는 `last_attacker`가 이미 있습니다. 봇은 공중 아래 J 사용 조건을 바꾸고, 선택으로 제3자 표적을 선호하게 합니다.

## 5. 진행 방법

스프라이트처럼 **한 번에 한 캐릭터**씩 합니다. 한 캐릭터를 이 순서로 진행합니다.

1. 사용자가 추천안·대안·그대로 중에서 고릅니다.
2. 바꾸기 전 기준선을 잽니다: 콤보 측정, 12시드 스윕.
3. 코드를 고치고, 캐릭터 킷 테스트와 회귀 테스트를 돌립니다.
4. 봇을 맞춥니다(`design/BOT_TUNING.md` 6절).
5. 같은 커밋에서 `design/SKILLS.md`를 고칩니다. 새 이펙트는 작업 목록에 `새 그림`으로, 계약이 바뀐 이펙트는 `다시 그림`으로 표시합니다. 그림이 생기기 전에는 가장 가까운 동작 줄과 도형으로 대신합니다.
6. 전후를 측정하고, 웹 빌드로 사용자가 손맛을 확인합니다.
7. `design/DECISIONS.md`에 기록합니다.

**추천 순서:** 겹침이 큰 곳부터 합니다.
1. Frey(K)
2. Rio(공중 아래 J, 제3자)
3. Nova(위 J)
4. Yuki(덫, 가두기)
5. Luna(작은 변경)

Frey를 먼저 바꾸면 "8방향 몸 돌진 K"가 Brave Luna와 Rio만의 것이 됩니다. Frey 밸런스 보류를 풀기 어려우시면 Rio부터 해도 됩니다.
