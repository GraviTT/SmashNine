# 소울 카드 풀 제안 (2026-11-24, 총괄)

사용자: "추천대로 해"(게임 품질 트랙, `reports/quality-systems-2026-11-24/README.md`의 2번).

카드는 고르셔야 넣을 수 있어서 제안서를 먼저 드린다. 아직 게임에는 아무것도 넣지 않았다.

## 고르는 법

- 아래 표의 카드마다 **넣기 / 빼기 / 고치기**를 답해 주시면 된다.
- "추천대로"라고 하시면 표 그대로 넣는다.
- 스킬 때처럼 직접 바꾼 내용도 된다.

## 지금 (6장)

| 카드 | 효과 | 종류 |
|---|---|---|
| Power | 공격 +12% | 수치 |
| Vitality | 최대 HP +15, 15 회복 | 수치 |
| Swiftness | 이동 속도 +8% | 수치 |
| Anchor | 받는 넉백 −15% | 수치 |
| Last Stand | 링아웃 피해 −30% | 수치 |
| Sky Step | 공중 점프 +1 | 행동 |

- 한 판에 세 번, 세 장 가운데 한 장을 고른다. 6장에서 뽑으니 판마다 거의 같다.
- 플레이를 바꾸는 카드는 Sky Step 하나다.

## 제안: 19장 (지금 6 + 공통 행동 8 + 캐릭터 전용 5)

한 캐릭터가 보는 카드는 15장이다(공통 14 + 자기 전용 1).

### 지금 6장: 그대로 둔다

### 공통 행동 카드 8장 (새로)

| 카드 | 효과 |
|---|---|
| 공중 대시 | 공중에서 가드 키를 누르면 바라보는 쪽으로 짧게 대시한다. 착지 전 한 번 |
| 유성 착지 | 높은 곳에서 떨어져 착지하면 주변에 충격파가 난다(평타 한 번쯤의 피해, 띄움) |
| 되받아치기 | 패리에 성공하면 그 상대가 1초 기절한다 |
| 소울 흡수 | 적을 탈락시키면 HP 25를 회복한다 |
| 마지막 불꽃 | HP가 30% 이하이면 공격 +25%, 이동 +10% |
| 추격자 | 적을 크게 날린 뒤 2초 동안 이동 +30% |
| 사냥꾼 | 몬스터에게 주는 피해 +50%, 몬스터와 크리스탈에서 얻는 소울 +50% |
| 궁극기 가속 | 궁극기 쿨다운 30초 → 22초 |

- 공중 대시가 가드 키를 쓰는 까닭: 가드는 땅에서만 되므로 공중에서는 그 키가 비어 있다.
- 회복량(HP 25, 15)은 경기 안 HP 그대로다. 기본 최대 HP는 100이다.
- 피해는 숫자 대신 "평타 한 번쯤"으로 적었다. 경기 안에서는 전투 피해에 0.26 배율이 걸려서, 코드의 숫자와 실제 깎이는 HP가 다르다(처음 판에는 "피해 8"이라고 적었다. 2026-11-25에 고침).

## 고르는 규칙 제안

| 규칙 | 지금 | 제안 | 까닭 |
|---|---|---|---|
| 세 장의 구성 | 전부 무작위 | 한 장은 반드시 행동 카드(공통 행동이나 전용) | 수치 카드만 세 장 나오는 판을 없앤다 |
| 전용 카드 | 없음 | 두 번째 고르기에 반드시 한 번 나온다 | 판마다 자기 캐릭터의 변화를 고를 기회가 있다 |
| 고르는 시간 | 5초(경기는 멈추지 않음) | 8초 | 카드가 늘어 읽을 시간이 필요하다 |
| 봇 | 무작위로 고름 | 그대로. 공중 대시는 봇이 복귀할 때 쓰게 한다 | 봇도 카드에 따라 달라진다 |

## 넣을 때 하는 일

- 아이콘은 임시(글자)로 넣고, 그림 후보는 Codex로 만들어 시안 월드컵에서 고른다.
- 같은 8판으로 경기 길이와 캐릭터별 결과를 다시 잰다.
