## 결론

혼합 시작 페어, 이동 중 공격 취소, Last Stand 재제안 제한, 봇 자동 선택 신호, 결과 화면의 실제 처리 동결은 수정됐다. 8인 동일 30시드에서는 Yuki가 0승에서 6승으로 회복했고, 링아웃은 705회에서 261회로 줄었으며, 매치 중앙값은 4:11에서 4:51로 늘었다.

그러나 이전 P0의 핵심 불변식은 아직 해결되지 않았다. 마지막 두 명이 같은 붕괴에서 함께 HP 0이 되면 `winner.is_defeated=true`, 생존자 0명인 채 승자가 선언된다. 서로 다른 두 렐름이 같은 웨이브에서 붕괴할 때는 렐름별로 배치를 닫기 때문에 먼저 한 명을 승자로 선언한 뒤 그 승자도 죽어 `finish_reason="last survivor"`까지 잘못 남는다.

## 새로 확인한 결함 — 심각도 순

### P0 — 동시 탈락 승자가 이미 탈락 상태이며, 다중 렐름 붕괴는 이벤트 단위로 묶이지 않는다

- 위치: `scripts/match/MatchDirector.gd:146-151`, `:190-202`, `:262-279`, `:302-311`.
- 같은 렐름 재현: Frey/Yuki HP 20, 같은 모서리, 150초 진행. 둘 다 `is_defeated=true`, `alive_count=0`, P1을 `simultaneous elimination` 승자로 선언.
- 분리 렐름 재현: HP 20인 두 명을 첫 웨이브의 서로 다른 모서리 0/2에 배치. 첫 렐름 처리 뒤 P2를 `last survivor`로 확정하고, 다음 렐름 처리에서 P2도 죽는다. 최종 상태는 `winner_id=2`, `winner_is_defeated=true`, `alive_count=0`.
- 원인: 동시 탈락 분기는 `fallen[0]`을 고르지만 그 노드는 이미 영구 탈락했다. 또 `_begin_batch/_end_batch`가 붕괴 이벤트 전체가 아니라 렐름 하나마다 닫힌다.
- 수정 제안: `MatchDirector`가 붕괴 이벤트 전체를 하나의 배치로 소유하고, 피해 적용 전에 동시 전멸 정책을 결정해 최종 승자는 실제 생존 상태로 남겨야 한다. 결과 UI나 Main에서 HP/탈락 상태를 사후 복구하는 것은 규칙 소유권을 어기는 우회책이다. 동시 전멸을 무승부로 할지, 사전 HP 순위 1위를 최소 1 HP로 남길지는 리드의 규칙 결정이 필요하다.
- 소유권 체크: **MatchDirector가 직접 수정 위치**. Main/HUD 보정은 부적합.

### P1 — 추가된 회귀 테스트가 P0의 잘못된 상태를 성공으로 승인한다

- 위치: `tests/test_match_rules.gd:356-379`.
- 증거: 테스트는 두 명이 모두 `is_defeated=true`인지 확인한 뒤 그중 Yuki가 winner인지 요구한다. `winner.is_defeated == false`, 생존자 1명, 서로 다른 붕괴 렐름은 검사하지 않는다. 그래서 현재 `Match rule tests passed (12)`가 P0와 동시에 성립한다.
- 수정 제안: 제품 규칙이 정해진 뒤 승자 생존/생존자 수 불변식과 분리 렐름 동시 붕괴 케이스를 이 테스트에 추가한다.
- 소유권 체크: **회귀 테스트는 `tests/test_match_rules.gd`**, 제품 수정은 **MatchDirector**. 분석 러너에서만 우회 판정하지 않는다.

### P2 — 새로 확인한 추가 제품 결함 없음

`052cbcb..HEAD`의 공격 취소, 혼합 페어, 카드 제안 제한, 자동 선택 신호, 명시적 피해 source, 캐릭터별 AI 사거리, 회복 공간/회복 AI 변경을 적대적으로 검토했다. 위 P0와 이를 놓친 테스트 외에 재현 가능한 새 제품 결함은 찾지 못했다. `git diff --check`의 유일한 항목은 `reports/lead-sweep/raw/fix1-8p.log` 끝의 빈 줄이며 제품 동작 결함이 아니다.
