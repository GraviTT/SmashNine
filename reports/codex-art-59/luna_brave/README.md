# CODEX-ART-59 Brave Luna 결과

## 현재 상태

**미납품.** 허용된 3회 생성 안에서 3번 통과 자세의 지지발 중심이 `76.0px`로 남았다. 목표는 `69.0±6px`이며 허용선보다 1px 오른쪽이다. 또한 내부 디테일이 idle 기준의 74.63-83.40%로 90% 기준을 충족하지 못했다. `art/bakeoff/luna/luna_brave-walk-v2.*`는 만들지 않았다.

## 측정값

- F3 지지발: `76.0px`; 목표 `69.0±6px` — 실패.
- F7 지지발: `70.0px`; 목표 `70.75±6px` — 통과.
- 연속 프레임 최대 발 이동: `21.5px` — 25px 이내.
- bob 이동: `[+2,+3,0,-3,0,+2,0,-2]px` — 모두 ±3px 이내, 발 행 유지.
- head scale: 점수 0.6 이상 프레임은 `1.00-1.06`; 나머지는 4× 보드로만 판정했다. 상한 1.04도 일부 넘었다.
- detail: `107.07-119.66`, idle `143.47`의 `74.63-83.40%` — 실패.
- spill 0, 테두리 비접촉, 4px 여백 — 통과.

## 4× 육안 판정

분홍 포니테일, 리본과 별 장식, 짧은 전투 드레스, 맨다리, 보라색 무릎높이 부츠와 양손 가드는 8프레임에서 유지됐다. F3/F7 모두 스윙 부츠가 지지 발목 옆에서 들렸고 두 교대 스텝으로 읽힌다. 다만 idle보다 세부 묘사가 부드럽고 F3 지지발 위치가 기준 밖이다.
