### 지도 장식 10개

길 2개, 표식 2개, 완료 3개, 잠금 3개는 **Python + Pillow로 정확한 1× 캔버스에 직접 그렸다.** 정수 좌표 다각형·선·픽셀로 형태를 만들고 최근접 확대만 사용했다. 안티앨리어싱·디더링·블러를 사용하지 않았다. 고정 팔레트는 카드의 10색만 쓴다. 표식은 하트 중심을 고정하고 불꽃 끝과 측면을 주기적으로 바꾼 서로 다른 6프레임이다.

길은 32px 주기 양 끝의 RGBA와 접선 방향을 맞췄다. 두 작은 잎은 청색, 뿌리는 금색/짙은 금색, 중앙은 보라 결에 작은 분홍·연보라 소울 점이 이어진다. 바깥으로 퍼지는 광원 대신 **한 픽셀 색 대비**로 희미한 빛을 표현했다.
