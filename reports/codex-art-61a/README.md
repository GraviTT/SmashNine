## 측정과 육안 판정

- 측정: 납품 11행은 spill 0, 이진 알파, 투명 테두리, 4px 여백을 통과했다. `attack`은 128px 셀에 들어가는 최대 실용 factor 0.22와 공통 X 오프셋 -12를 사용했다.
- 육안: 납품 행은 얼굴 1개, 양손, 검, 부츠가 프레임마다 유지되고 동작 방향이 읽힌다. `plunge`, `jump`, `hurt`는 자동 머리 측정 대신 4× 크롭으로 기준 앵커와 비교했다.
- 남은 문제: `attack`은 셀 맞춤 예외 때문에 앵커보다 명확히 작다. `walk`은 머리 일치 factor에서 152×130이 되어 128px 셀을 넘는다. `fall`은 세로 자세가 128px 셀을 넘는다. `shield`는 머리 0.94와 4px 여백 실패가 동시에 남았다. `infinity_overdrive`는 머리 일치 factor에서 머리 위 검이 셀 상단을 넘는다.
