# 분리 효과 보존본

`*_removed-fx.png`는 576×384 원래 셀 좌표를 유지한 검수용 픽셀 보존본이다. 게임에 연결하지 않았다.

나방·양·딱정벌레·별 표시는 마스크로 분리했다. 위습·임프·드론·오라클은 발사 효과가 몸을 가리므로, 이 보존본에는 겹친 몸 픽셀도 포함될 수 있다. 독립 VFX로 바로 사용할 완성 자산이 아니다. 해당 몸 프레임은 이웃 자세를 참조해 다시 그렸으며 가려진 원래 픽셀의 정확한 복원이라고 주장하지 않는다.

까마귀 파일은 게임 시트에 보이는 잘린 발사체 부분을 보존한 것이다. 온전한 발사체는 로컬 raw 원본에 남아 있다. 분리 방식과 좌표는 `../repair.py` 및 후보 JSON을 참고한다.
