## 여섯 가지 추가 분석

### 1. Dead band

유효한 `engage + move 0 + jump false + attack 없음` 5초+ episode는 2건뿐이고, 둘 다 **gap width 0**이다. 즉 원래 발판 틈 dead band의 재발이 아니다.

|---|---:|---|---|---|---:|---|
| 105@80.63 | 10.07초 | Luna/monster/r1 | P(5921.5,546.4) / T(5868.8,345.9) | 207.3–207.3 (207.3→207.3) | 0 | in fighting range |
| 108@89.30 | 5.65초 | Yuki/crystal/r4 | P(9766.1,3462.2) / T(9770.0,3645.0) | 178.6–184.9 (182.9→178.7) | 0 | too close: keeping range |

seed 112는 이 episode 0건, 20초+ 대치 0건이다. 전체 20초+ 대치는 seed 101 `29.9초`, seed 103 `89.6초`, seed 108 `29.7초`였으며 seed 103은 두 선수가 서로가 아니라 monster를 상대하고 recovery를 반복한 시간이라 원래 gap dead band와 다르다.

```text
R7: 같은 층이면 항상 progress → 막힌 틈에서도 timer=0 → 188.9초 정지
R8: 표적 방향 blocked 확인 → 2.5초 뒤 drop/재탐색 → seed 112 정지 0건
```
