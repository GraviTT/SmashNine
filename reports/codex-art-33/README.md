# CODEX-ART-33 결과 보고

## 완료 범위

Part 1~3을 모두 완료했다. ART-32가 각 프레임에 대기 머리를 덧붙여 두 머리처럼 보이게
만든 원인을 제거했고, JSON을 신뢰하지 않고 프레임에 원래 그려진 머리를 다시 측정하는
감사기를 만들었다. `Frey.gd` 행 테이블과 전투 수치, 판정, 입력, 타이밍은 변경하지 않았다.

- 합성 배율 검증은 모두 오차 3% 이내였다.

- 합성 이중 머리: 얼굴 2개/눈 군집 3개를 검출해 차단했다.
- 보관한 ART-32 실패 시트: 35프레임 중 32프레임을 붙여넣은 머리로 검출했고, 최고

전체 수치는 `head_validation.txt`에 기록했다.

## Part 2 — 한 프레임 한 그림인 몸 레이어

ART-32의 여덟 `*_body_source.png`를 직접 확인했다. 이 원본들은 머리를 붙이기 전의
완전한 전신 그림이며, 각 포즈에 이미 그려진 머리는 하나였다. 따라서 카드가 허용한 재사용
경로로 35프레임을 다시 만들었다.

몸 픽셀에 적용한 작업은 다음이 전부다.

1. 원본 스트립에서 연결된 전신 포즈 전체를 한 번 자른다.
2. 그 포즈에 그려진 머리를 측정해 전신 전체에 하나의 배율을 적용한다.
3. 최근접 이웃 방식으로 전신 전체를 한 번 축소한다. 머리·얼굴·팔다리·장비를 따로 합성하거나
   다른 그림에서 붙여넣지 않는다.
4. 정본 Frey 팔레트 192색으로 양자화하고 알파 0.5를 기준으로 완전 투명/불투명화한다.
5. 128×128 셀에 놓고 지상 프레임 발을 y=120에 맞춘 뒤 셀의 바깥 1픽셀을 비운다.
   별도 트림은 없다.

프레임별 자르기 좌표, 원본 머리 단위, 초기 배율 0.225, 보정 배율, 최종 배율, 결과 크기와
배치 좌표는 `body_pixel_operations.txt`에 빠짐없이 기록했다. 효과는 완성된 몸 위에만 한 번
합성했다.

내장 ImageGen으로 `descent` 비교 후보 1회를 생성했다. 참조는 `frey_sheet.png`,
`frey_illustration.png`, 기존 `descent_body_source.png`였고, “왼쪽에 정본 대기 자세 앵커,
오른쪽에 같은 크기의 6개 하강 포즈, 투명 배경, 효과·텍스트·격자·붙인 머리 없음”을
요청했다. 후보에는 7개 전신이 있었지만 왼쪽이 대기 앵커가 아니라 다른 전투 포즈여서
폐기했다. 세 번 제한 중 한 번만 사용했으며, 최종 자산에는 검증된 기존 전신 원본을 썼다.

## Part 3 — 산출물과 미리보기

- `frey_moves_body_sheet.png`: 768×1024 RGBA, 몸/장비 레이어
- `frey_moves_fx_sheet.png`: 768×1024 RGBA, ART-32 효과 레이어 유지
- `frey_moves_sheet.png`: 768×1024 RGBA, 몸 위에 효과를 합성한 런타임 시트
- `frey_moves_heads.json`: 35프레임 머리 중심·배율·눈 군집 메타데이터. 텀블 회전
  프레임도 런타임 계약에 따라 측정 중심을 기준으로 28×32 박스를 기록한다.
- `frey_moves_README.md`: D32/ART-33 제작 규칙과 재현 절차
- `tests/art_preview/frey_heads_33/`: 행별 3배 전/후 비교 8장, 전체 머리 박스 시트,
  ART-32 실패 고정본, 생성기와 측정기

런타임 연결 함수는 변경하지 않았다. 기존 Frey 행 이름·순서·프레임 수가 그대로여서
현재 로더가 새 `frey_moves_sheet.png`를 같은 방식으로 사용한다.

Godot가 모든 실행에서 출력한 `Failed to read the root certificate store`는 카드에 명시된
샌드박스 잡음이다. 그 외 `ERROR`, `SCRIPT ERROR`, `Parse Error`는 최종 테스트에 없었다.
기본 사용자 캐시 경로로 실행한 첫 import에는 샌드박스 쓰기 제한 오류가 있었으므로 폐기했고,
프로세스 한정 `LOCALAPPDATA`/`APPDATA`를 쓰기 가능한 임시 폴더로 지정한 최종 import에서
인증서 잡음 외 오류가 없음을 확인했다.

## 사람이 판단할 부분

수치 검증은 머리 크기, 이중 머리, 셀 경계, 행 계약을 보장한다. 실전 크기에서 각 포즈의
얼굴 가독성, 실루엣의 박력, 기존 Frey 화풍과의 미감상 일치, 몸과 기존 효과의 연출 조화는
사람이 비교 시트를 보고 최종 판단해야 한다.

## 제한 사항

- ImageGen 비교 후보는 앵커 요구를 지키지 않아 최종 자산에 사용하지 않았다.
- 프로젝트에는 작업 시작 전부터 다른 테스트용 `.csv`가 존재하지만 ART-33은 `.csv`를
  새로 만들지 않았다. 해당 파일들은 이 카드의 쓰기 허용 범위 밖이며 이번 변경에 포함하지 않는다.
- 샌드박스에서 `.git`은 읽기 전용이므로 실제 커밋 대신 허용 경로만 스테이징하는
  `commit.ps1`을 제공한다.
