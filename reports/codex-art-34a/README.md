# CODEX-ART-34A 결과 보고

## 완료 범위

담당한 Frey, Rio 남성, Rio 여성, Yuki의 메인 시트에서 **row 1(walk)만** 새 6프레임
걷기 사이클로 교체했다. 모든 프레임은 한 장의 완전한 전신 그림이며 머리·얼굴·팔다리·장비를
다른 프레임에서 붙여 넣지 않았다. 전투 수치, 판정, 입력, 타이밍, 봇, 제품 코드는 변경하지 않았다.

## Part 1 — 걷기 원본 생성

내장 ImageGen을 사용해 캐릭터별로 `대기 앵커 1 + 걷기 6` 전신을 한 이미지에 생성했다.
참조는 각 캐릭터의 현재 메인 시트와 메인 일러스트다.

- Frey: 1라운드 채택
- Rio 남성: 1라운드 발 변화 41.7%로 미달하여 2라운드 채택
- Rio 여성: 1라운드 채택
- Yuki: 1라운드 발 변화 39.5%로 미달하여 2라운드 채택

최종 원본과 미채택 1라운드는 `source/`에 보관했고 전체 프롬프트 구조와 2차 수정 지시는
`imagegen_prompts.md`에 기록했다.

## Part 2 — 전신 단위 후처리와 시트 반영

`tests/art_preview/walk_34/a/build_walks.gd`가 Godot `Image` API로 다음 작업만 수행한다.

1. 2172×724 투명 원본을 7개 구간으로 나누고, 각 구간에서 가장 큰 연결 전신 그림을 찾는다.
2. 전신 경계 안의 작은 분리 생성 잡음만 제거한다. 머리·팔다리·장비 내부를 따로 자르거나
   합성하지 않는다.
3. 같은 시트 대기 머리에 맞도록 **전신 전체** 배율을 조절한다.
4. 최근접 축소 후 해당 시트의 상위 192색 팔레트로 양자화하고 알파를 0/1로 고정한다.
5. 128×128 셀의 발을 y=120에 두고 4px 안전 여백과 1px 빈 테두리를 유지한다.
6. 기존 row 1을 교체하기 전, 나머지 6개 행이 저장 뒤에도 픽셀 단위로 동일한지 비교한다.

최종 메인 시트는 모두 768×896 RGBA PNG다.

- `assets/art/frey/frey_sheet.png`
- `assets/art/rio/rio_male_sheet.png`
- `assets/art/rio/rio_female_sheet.png`
- `assets/art/yuki/yuki_sheet.png`

런타임 연결 변경은 없다. `PlayerBase.ORIGINAL_SHEET_ROWS`의 기존 `walk = row 1, 6 frames,
10 fps, loop` 계약이 같은 파일을 자동으로 사용한다.

## Part 3 — 측정·접촉 시트·어니언 스킨

| 캐릭터 | 변경 전 발 변화 | 변경 후 | 머리 배율 범위 | 얼굴 후보/프레임 | 결과 |
|---|---:|---:|---:|---:|---|
| Frey | 33.2% | 50.4% | 0.9906–1.0412 | 1 | PASS |
| Rio 남성 | 25.9% | 77.5% | 0.9574–1.0458 | 1 | PASS |
| Rio 여성 | 24.6% | 50.8% | 0.9545–1.0220 | 1 | PASS |
| Yuki | 49.2% | 53.2% | 0.9575–0.9997 | 1 | PASS |

세부 발 너비는 `measurements.txt`, 프레임별 배율·머리 상자·눈 군집은
`head_validation.txt`, 모든 전신 픽셀 작업은 `body_pixel_operations.txt`에 기록했다.

`tests/art_preview/walk_34/a/`에는 캐릭터마다 다음 두 장이 있다.

- `*_walk_before_after_heads_3x.png`: 대기 앵커 + 변경 전/후 6프레임, 머리 상자와 배율
- `*_onion_before_after_3x.png`: 변경 전/후 6프레임 저불투명도 중첩

접촉 시트는 2688×840, 어니언 스킨은 768×384 PNG다.

## 확인 및 테스트

| 검증 | 결과 |
|---|---|
| 발 변화율 `walk_feet.gd` | 4/4 PASS, 모두 45% 이상 |
| 머리 배율 | 24/24 PASS, 모두 ±5% |
| 한 머리/눈 군집 검사 | 24/24 PASS, 얼굴 후보 1, 눈 군집 0–1 |
| 비-walk 행 픽셀 비교 | 4/4 PASS, 모두 동일 |
| `test_sprite_frames.gd` | PASS — 8 메인 시트, 184프레임 |
| `test_art.gd` | PASS — original/prototype 전 캐릭터·체형 |
| `--headless --import` | PASS, exit 0 |

모든 Godot 실행의 `Failed to read the root certificate store`는 카드에 명시된 샌드박스
잡음이다. 그 외 `ERROR`, `SCRIPT ERROR`, `Parse Error`는 최종 검증에 없었다. 이번 작업은
`.csv` 파일을 만들지 않았다. 임포트 로그에 나온 CSV는 작업 시작 전부터 있던 허용 범위 밖 파일이다.

## 사람이 판단할 부분

자동 검사는 크기, 경계, 한 머리, 행 보존, 발 실루엣 변화량을 보장한다. 실제 10fps 재생에서
접촉→다운→패싱이 자연스러운지, Rio 남성의 큰 보폭이 걷기보다 달리기처럼 느껴지지 않는지,
Frey의 방패·검과 Yuki의 긴 머리/옷자락이 다리 동작을 충분히 읽히게 하는지는 사람이 접촉 시트와
모션 뷰어에서 최종 판단해야 한다.

## 제한 사항

- 카드 지시대로 창 실행은 하지 않았으며, 실제 게임 화면 스크린샷 대신 접촉 시트와 어니언
  스킨을 제공했다.
- 전체 테스트 모음이나 소크 매치는 실행하지 않았다. 아트 카드가 지정한 두 회귀 테스트와
  임포트, 전용 측정만 실행했다.
- `.git`이 읽기 전용이라 직접 커밋하지 못했다. `commit.ps1`은 허용된 경로만 스테이징한다.
