# SART-02 · 스토리 시작 카드 후보 작업 인계

## 현재 상태 — 생성 완료, 최종 납품 처리 미완료

기본 18개(v1/v2)와 자체 검수 수정 8개를 생성해 원본 26개를 보존했다. 게임 프로젝트는 변경하지 않았다. 모든 원본을 전체 크기로 확인하고 잠정 추천 세트를 골랐다.

**완료 조건 전체는 충족하지 못했다.** 설치된 Python 3.12 실행이 샌드박스에서 접근 거부되어 Pillow로 최종 640×360 PNG와 비교판을 만들지 못했다. 실행 가능한 Blender Python 3.13에는 Pillow가 없다. 패키지 설치·다운로드는 하지 않았다. 기존 Sharp/libvips로 대체 처리할지 사용자에게 질문했으나 이 보고서 작성 시 답변은 없었다. 대체 처리는 실행하지 않았다.

## 확인한 것과 남은 작업

- 완료: 생성 반환 경로에서 원본 26개 복사 및 SHA-256 일치 확인. 전체 원본에서 인물·얼굴·문자 유사 표시 육안 검사. 실제 프롬프트와 참조 기록.
- 완료: Pillow 제작 스크립트 Python AST 문법 검사. 이는 Pillow 실행 테스트가 아니다. git status로 제품 소스 변경 없음 확인.
- 남음: 허용되는 Pillow 환경에서 스크립트 실행, 640×360 PNG/JSON 26쌍 작성, 최종 크기·불투명도·밝기·채도 재측정.
- 남음: 최종 PNG 640×360과 480×270 전수 재검수. 특히 9번 v3 크롭의 문자 유사 점 제거, 3·7번 수평선, 7번 짐승 표현 확인.
- 남음: Pillow+맑은 고딕 JPEG Q90 비교판 10장 제작 및 육안 확인, 파일당 2MB 이하 확인.

## 커밋

현재 .git은 쓰기 허용 대상이 아니므로 커밋하지 않았다. [commit.ps1](commit.ps1)은 허용 후보·보고서만 스테이징하고 art/raw/를 제외한다. 후보 최소 18개와 비교판이 없으면 커밋을 중단한다. 커밋 메시지 마지막 줄은 요구된 Co-Authored-By다.


마지막 인계 검증: [handoff-validation.json](handoff-validation.json). 26개 ID 고유성, 실제 원본 형식, 모든 참조 입력, 16:9 크롭 계획, 매니페스트 일치, 커밋 메시지 말미를 확인했다. commit.ps1도 PowerShell 구문 검사만 통과했으며 실행하지 않았다.
