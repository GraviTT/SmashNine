# CODEX-ART-41 — Frey `descent` 검 꽂기 후보

## 결과

`frey-descent-v4`를 1152×192 스트립(192px 셀 6개, 14fps)으로 만들었다. 기존 v3의 자연스러운 착지와 일어서기를 없애고, 검끝이 수직 낙하를 이끈 뒤 F5–F6에서 한쪽 무릎을 꿇고 검을 바닥에 박은 상태로 끝나도록 바꿨다. 게임이 그리는 충격파·먼지·발광 등은 넣지 않았다.

두 번 생성했고, 검끝 선행 낙하와 박힌 종료 자세가 더 명확한 `attempt2`를 선택했다. 원본은 `art/raw/frey-41/attempt2.png`, 정규화 입력은 `art/raw/frey-41/prepared2.png`다.

## 프레임별 육안 확인 (4×)

- **F1 — 축적:** 지상에서 깊게 웅크리고 방패를 전방에 둔 채 검을 낮게 뒤로 뺀다. 다음 도약을 위한 압축이 읽힌다.
- **F2 — 도약:** 무릎을 접고 검을 머리 위로 올린다. F1의 낮은 자세에서 위로 풀리는 방향 전환이 분명하다.
- **F3 — 뒤집기:** 몸을 세운 채 검을 가슴 앞에서 수직 아래로 돌린다. 검끝이 발 아래로 내려와 급강하 준비가 읽힌다.
- **F4 — 급강하:** 몸과 검이 한 수직축에 있고 검끝이 가장 아래에서 낙하를 이끈다. 머리카락과 망토가 위로 솟아 하강 속도를 보여 준다.
- **F5 — 강타:** 한쪽 무릎을 바닥에 대고 양손으로 손잡이를 눌러 검을 바로 앞 바닥에 꽂는다. 칼날은 y=152에서 끝나며 묻힌 부분은 그리지 않았다.
- **F6 — 박힌 종료:** 일어나지 않고 F5보다 조금 더 낮게 눌린 자세를 유지한다. 검은 계속 박혀 있고 머리카락만 가라앉기 시작한다.

한 얼굴, 연결된 양팔·양다리, 검과 방패가 전 프레임에 남아 있는지 확인했다. F5–F6은 기존 v3처럼 방어 자세로 회복하지 않는다.

## 측정값

측정과 육안 판정은 구분했다.

- `factor`: **0.347** (시트 전체 단일 배율)
- `lift_scale`: **0.0**
- `head_scale`: **0.96** (`head_scale.py`, 앵커 `frey-idle-v2.png:0`, 신뢰도 기준을 넘은 2프레임 중앙값)
- 프레임별 헤드 추정: `0.92, 0.86, 1.00, 0.86, 0.90, 0.92`; 자세가 크게 꺾인 프레임은 매칭 신뢰도가 낮아 중앙값에서 제외됐다.
- 육안상 머리·얼굴·장비 크기는 4× 앵커 옆에서 급격한 프레임별 변동 없이 유지된다.
- 출력: 1152×192, 발/검끝 선 y=152, F4 위 여백 4px, 전체 border clear 및 4px margin 통과.
- detail: 107.33–116.67, spill: 전 프레임 0, alpha: binary.

## 시각적 확인

[4× 비교판](./compare.png)은 같은 픽셀 배율로 `앵커 → 현재 게임 row 7 → v4 후보`를 세 줄에 놓았다. 빨간 선은 y=152이며 F5–F6의 무릎·발·검끝이 이 선에서 끝나는지 확인할 수 있다.

## 아직 잘못되었거나 주의할 점

- 생성 원본의 공중 프레임 높이 좌표가 일관되지 않아 `lift_scale 0.0`으로 바닥선을 우선했다. 따라서 F2–F4의 공중 높이는 셀 내부 위치보다 접힌 다리, 수직 검, 위로 솟은 머리카락 같은 **자세 실루엣**으로 표현된다. 실제 게임의 공중 사용에서는 캐릭터 물리 이동이 낙하를 보완해야 한다.
- F5와 F6의 차이는 의도적으로 작다. F6은 더 낮게 눌리고 머리카락이 조금 가라앉지만, 빠른 재생에서 홀드 프레임처럼 보일 수 있다.
- F4는 위쪽 여백이 정확히 4px라 더 큰 배율은 사용할 수 없다.
- 후보만 만들었고 `smash-nine-prototype/`에는 반영하지 않았다.

## 확인 및 테스트

- 정규화 파이프라인: 6프레임, 공통 배율 0.347, border clear, 4px margin, spill 0, alpha binary.
- `head_scale.py`: 중앙값 0.96.
- 4× 비교판에서 앵커, 현재 게임 행, v4를 같은 픽셀 배율로 확인했다.
