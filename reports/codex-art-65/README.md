## 측정

- 납품 3행은 border clear, 4px margin, spill 0, 이진 알파, detail 79 이상을 모두 통과했다.
- 걷기 8프레임도 개별 margin·spill·detail·머리 크기는 통과했다. 3번 지지발 중심 77.5px, 7번 75.0px로 이웃 발의 중간 범위 안이다.
- 걷기 bob 이동은 `[-2, 0, 5, -2, 0, -1, 3, -5]px`로 3·8번이 허용치 ±3px를 넘는다. 3번은 `walk_feet.py`가 지면 접점 두 개(60.0, 77.5px)를 검출해 단일 지지발 조건도 실패했다.

## 4× 육안 판정

- `fall`: 무릎과 팔을 모은 낙하 자세가 읽히며 얼굴 하나, 양손, 검, 부츠와 짧게 접힌 망토가 유지된다.
- `shield`: 검이 몸 앞에 붙고 6프레임이 올리기→버티기→회복으로 읽힌다. 장벽은 없다.
- `infinity_overdrive`: 낮은 자세에서 검을 머리 높이로 비스듬히 들어 셀 상단을 피하고, 지휘 동작과 회복이 읽힌다. 추가 검과 이펙트는 없다.
- `walk`: 의상과 짧은 실루엣은 맞지만 위의 수치 실패가 남아 납품하지 않았다. 최선 시도는 `walk/best.png`에만 보존했다.

제품 Godot 파일은 변경하지 않았고, 아트 후보 작업이라 Godot 실행 테스트는 하지 않았다.
