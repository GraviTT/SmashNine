# AUD-02a · 여섯 최종 분석 그림의 직접 관찰

2026-10-23. 직접 소리를 듣지 않았다. 여섯 개의 최종 PNG를 이미지 뷰어로 열어 **전곡 파형 / 스펙트로그램 / 경계 ±10ms**를 모두 확인했다. 그림은 실제 납품 PCM16 WAV를 다시 읽어 그린 것이다.

| 그림 | 실제로 보이는 점 | 경계 관찰 |
|---|---|---|
| `music_title-a.png` | 펄스의 규칙적인 배음 선, 음 사이 여백, 계단 모양의 짧은 주기 파형. 강한 에너지는 저역과 선율 근음에 있고 8kHz 위의 연속 밝은 잡음 띠가 없다 | 0ms에서 기존 펄스 주기가 이어지고 새 박 어택은 그 뒤에 자란다. 끝에서 무음으로 내려가지 않는다 |
| `music_title-b.png` | 펄스보다 적은 고역 배음, 지속적인 중저역 화성 띠, 경계의 둥근 사인/FM 모양. 좌우가 대체로 일치하되 패드·방 잔향의 작은 차이가 있다 | 0ms에서 곡선이 연결된다. 주변 400ms 대비 경계 RMS +0.15dB로 거의 같은 에너지 |
| `music_title-c.png` | 펄스 배음 선과 아래의 패드 띠가 함께 있다. B보다 선율 배음이 풍부하고 드럼은 짧게 나타난다 | 경계의 독립적인 수직 단절이나 평평한 무음이 없다. 첫 박에서 에너지가 자연스럽게 늘어난다 |
| `music_battle-a.png` | 타이틀보다 촘촘한 저역 박과 짧은 고역 타격. 중간 긴 음 뒤 다시 짧은 훅으로 돌아오는 패턴이 보인다 | 경계 앞의 펄스가 계속되고 경계 뒤 짧은 잡음 타격이 겹친다. 마지막 표본에서 진폭이 잘려 0이 되지 않는다 |
| `music_battle-b.png` | 밀도 높은 저역 박과 매끄러운 선율·화성, 고역 전체를 덮는 연속 잡음이 없다. 전곡 파형에 타격의 봉우리가 남아 있다 | 0ms에서 둥근 파형이 이어진다. 경계/주변 에너지는 +0.0007dB로 사실상 같다 |
| `music_battle-c.png` | A의 펄스 선율, B와 유사한 패드 띠에 짧은 드럼층이 겹친다. 킥·스네어의 봉우리는 있으나 전곡 파형의 평평한 클리핑 천장이 없다 | 0ms 연결이 유지되며 뒤에서 타격이 커진다. 경계/주변 +0.98dB로 에너지 꺼짐이 없다 |

전곡 진폭 축은 ±1 FS, 경계 확대는 ±0.5 FS, 스펙트로그램은 고정 −80~0dBFS로 통일했다. 그림마다 자동 대비·진폭 확대를 달리하지 않았다. 스테레오 스펙트로그램은 좌우 평균이며 파형과 수치 검사는 양 채널을 사용한다.

**한계:** 스펙트로그램의 고역 여백은 효과음이 실제로 잘 들린다는 증거가 아니다. 부드러움·선명함·피로도·선율의 기억성·음악적 연결감은 사용자 청음이 필요하다. 경계 검사는 WAV의 연속성을 뒷받침하며 HTMLAudioElement나 Godot의 재생 스케줄링까지 검증한 것은 아니다.
