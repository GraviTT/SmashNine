# AUD-02 시각 검토

`overview.png` 전체와 선택 A·스토리 B·결과 C의 개별 원본을 확대해 확인했다. 다른 여섯 후보는 모음 그림에서 비교했다. 아래는 청각 평가가 아닌 시각적 관찰이다.

고정 축: 파형 ±1 FS, seam ±0.5 FS, 스펙트로그램 −80~0 dBFS·40~22,050Hz 로그축. 고정 축이라 같은 진폭·색이 같은 수치를 뜻한다.

| 후보 | 관찰 |
|---|---|
| [music_select-a](music_select-a.png) | 반복적인 저음 타격과 선명한 수평 배음. 펄스 계단형 경계 파형은 주황선 양쪽으로 이어진다. |
| [music_select-b](music_select-b.png) | A보다 위쪽 배음선이 적고 경계는 매끈한 주기 파형. 중앙 경계 뒤 정상 저음 어택의 진폭 상승이 보인다. |
| [music_select-c](music_select-c.png) | A와 비슷한 펄스 배음에 낮은 패드가 더해진다. seam의 L/R 선이 거의 겹치며 경계 후 진폭이 커진다. |
| [music_story-a](music_story-a.png) | 선택보다 긴 음 블록, 높은 배음은 크게 줄고 드럼 수직선이 드물다. 경계 파형이 낮은 진폭으로 이어진다. |
| [music_story-b](music_story-b.png) | 저역·중역에 긴 수평선이 모이고 드문 북만 위로 솟는다. seam은 완만하며 경계에 독립적인 수직 단절이 보이지 않는다. |
| [music_story-c](music_story-c.png) | 완만한 선율·패드 블록과 짧은 수직 타격이 보인다. 칩 배음이 선택 C보다 훨씬 적으며 경계에서 바닥 무음이 없다. |
| [music_results-a](music_results-a.png) | 첫 두 마디에 짧은 선율 배음과 타격이 모이고 이후 긴 음으로 바뀐다. 9마디에 훅의 배음이 다시 나타난다. |
| [music_results-b](music_results-b.png) | 첫 두 마디 뒤 선율의 간격이 넓어진다. 경계는 매끈한 주기 파형이며 전체 진폭에 사각형 잘림이 보이지 않는다. |
| [music_results-c](music_results-c.png) | 도입부의 고역 타격과 칩 배음, 이후 긴 패드가 구별된다. seam 주황선 양쪽의 펄스 주기가 이어진다. |

그림은 전곡의 모든 순간·주파수·음악적 이음을 보장하지 않는다. 실제 청음, 브라우저의 WAV 디코딩·루프 스케줄링, 게임 내 음악/SFX 믹스 검증은 남아 있다.
