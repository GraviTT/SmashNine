# CODEX-ART-50 — Yuki 메인 아트 후보

## 결과

Yuki 메인 일러스트와 얼굴 초상화 후보를 두 세트 만들었다. 둘 다 후보이며 게임에는 넣지 않았다.

- `yuki_illustration-v1.png`: 오른손에 부적 부채를 펼치고 왼손을 낮게 연 침착한 준비 자세
- `yuki_illustration-v2.png`: 오른손 두 손가락 사이에 부적 한 장을 세우고 왼손의 작은 부채를 허리 가까이 모은 자세
- `yuki_face-v1.png`, `yuki_face-v2.png`: 각 전신에서 512×512 영역을 잡아 LANCZOS로 256×256 축소
- `contact.png`: 설치된 Frey·Luna와 두 Yuki 후보를 25% 전신 + 얼굴로 비교
- `anatomy-check-1x.png`: 팔·손·소매·발을 원본 1배로 모은 검수판
- `face-check-2x.png`: 얼굴 후보를 2배로 본 검수판
- `metrics.json`: 파일·알파·여백·프린지 측정값

## 원본 크기 육안 검수

전신 두 장을 각각 1024×1536 원본 크기로, 얼굴 두 장을 `face-check-2x.png`에서 2배로 확인했다.

- v1: 양팔이 어깨에서 손목까지 자연스럽게 이어지고 흰 소매가 상완 장식에 연결된다. 펼친 왼손은 다섯 손가락이 분리되어 있고, 오른손은 부적 부채를 자연스럽게 쥔다. 두 부츠와 모든 소매 끝이 캔버스 안에 있다.
- v2: 들어 올린 오른팔과 허리 앞 왼팔의 연결이 자연스럽다. 오른손은 부적을 검지·중지 사이에 두고 나머지 손가락이 접힌 구조이며, 왼손은 부적 부채를 쥔다. 두 부츠와 양쪽 소매가 모두 온전히 보인다.
- 공통: 긴 검은 머리의 보라 광택, 붉은 눈, 흰 긴 소매, 빨강·검정 의상, 금색 무늬의 붉은 부적, 어두운 부츠를 확인했다. 손에서 떨어진 부적·배경·발광·마법 효과·문자·로고는 없다.

## 아직 맞지 않는 부분

- 머리 장식이 스프라이트의 명확한 “흰 점이 있는 붉은 리본”보다 붉고 흰 매듭끈처럼 보인다. 금색 방울은 유지됐다.
- 허리와 치마의 끈·금장·겹단이 작은 스프라이트보다 더 화려하다. 기존 Yuki 얼굴 참고 그림의 장식성이 일부 남은 결과다.
- v2의 든 부적이 검지와 중지를 가려, 축소했을 때 손가락 구분이 v1보다 약하다. 원본에서는 관절과 손가락 수를 확인할 수 있으나 후보 선택 때 볼 항목이다.
- Frey·Luna와 선·채색 마감은 같은 계열이지만 Yuki의 머리카락과 허리 장식 밀도가 조금 더 높다.

## 제작 방식

내장 이미지 생성 도구로 각 자세를 만들고 사용한 생성물을 `art/raw/mainart-50/`에 복사했다. 균일한 `#00FF00` 배경을 수치적으로 키잉한 뒤 소프트 알파와 가장자리 디스필을 적용하고, 전신을 88% 높이에 맞췄다. 후처리는 `process_art.py`로 재현할 수 있다.
