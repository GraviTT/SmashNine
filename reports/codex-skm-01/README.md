## 검수 결과
- **hover_dash (미전달, 2차):** 두 번 생성 후 미전달. 1차 F4 검이 금색으로 바뀌고, 2차 F4에서는 검날이 보이지 않는다. 2·3번의 공중 수평 정지 자세도 충분히 분명하지 않다. 2차를 검토용으로 보존했다.
- **launch_chase (미전달, 2차):** 두 번 생성 후 미전달. 1차 흰 치마 형태의 의상 변경은 2차에서 개선했다. 2차 배율 0.315, 공중 높이 계수 0.5에서 여백·번짐·디테일은 통과하지만 얼굴 눈 비율 0.879–0.944, 폭 0.886–1.029로 기준 미달이다. 얼굴에 맞게 더 키우면 F2의 올린 검이 상단 여백을 침범한다. F2의 발이 지면에 남고 F4 추가타가 머리 높이보다 낮은 점도 남았다.
- **shield_bash (미전달, 2차):** 두 번 생성. 최선 2차 공통 배율 0.336에서 눈 0.969–1.037은 목표 범위, 얼굴 폭은 F2·F4가 1.057로 목표 1.04를 넘는다. 자동 머리는 전 프레임 1.00. 여백·번짐·디테일·검과 방패·지상 접지는 통과하나 SKM-01 엄격 기준에서는 미전달이다. 방패를 당기는 준비와 앞다리에 체중을 싣는 정도는 사람이 판단할 부분이다.
- **sword_plant (미전달, 2차):** 두 번 생성 후 미전달. 2차에서 준비 때 검을 띄우고 삽입·누르기·회수를 구분했다. F1 얼굴이 팔과 검에 가려져 자동 표식·머리값은 무효이며 통과 근거에서 제외했다. 배율 0.32에서 F2–6 눈 비율 0.922–1.055, 폭 1.000–1.043로 기준 밖이다. 허벅지 의상과 무릎 갑옷 형태도 기준과 차이가 남는다.
- **air_hover_swing (미전달, 2차):** 두 번 생성 후 미전달. 1차는 긴 F3 검 때문에 몸 중심을 왼쪽 17px 옮겨야 했으며 얼굴도 기준 미달이었다. 2차는 중심 x=96을 유지하고 192px 셀에 맞지만 눈 비율 0.895–0.994, 얼굴 폭 1.043–1.114로 기준 밖이고 일부 자세의 허벅지 노출이 기준과 다르다. 2차의 짧아진 베기 동작을 검토용으로 보존했다.

## 측정 방법과 제한
- 각 자세의 연결된 그림 덩어리를 따로 추출했다. 고정 너비 칸으로 자르지 않았으며 원본의 공통 세로 좌표를 보존했다.
- 행당 배율 하나, 축소만 사용. LANCZOS / sharpen 60 / despill auto / palette none / #00ff00. 몸·머리·무기를 따로 붙이거나 프레임별 크기를 변경하지 않았다.
- head_scale.py와 ART-72 얼굴 표식 검사, 기준과 나란한 4배 판으로 확인. 얼굴 자동 표식은 제안값이며 육안과 일치하지 않으면 통과 근거로 쓰지 않는다.
- 후보 전달 기준은 이 카드의 엄격한 얼굴 0.96–1.04를 적용했다. ART-77의 완화 구간을 자동으로 적용하지 않았다.
- 게임 실행이나 모션 뷰어 채택은 수행하지 않았다.

## 사람이 판단할 것
동작의 정지감·가속감, 추가타 구분, 방패의 무게감, 의상 일치와 얼굴 크기를 검토해야 한다. 미전달 행은 실패 근거를 보존한 검토 자료이며 채택 후보가 아니다.

## 남은 작업
미도달 행 없음. 미전달 행의 재작업은 별도 후속 작업이다.

commit.ps1은 작성만 하며 실행하지 않는다. 원본은 art/raw/skm-01/에 보존하고 커밋 대상에서 제외한다.

## 파일 검증
verify_skm.py로 최종 PNG 규격·알파·여백·번짐·디테일·배율·추출 기록·전달 상태·커밋 대상 범위를 확인했다. 세부 결과는 [audit.json](audit.json). 이 파일 검사의 통과는 그림의 채택이나 얼굴 기준 통과를 뜻하지 않는다.
PowerShell 파서로 commit.ps1의 구문을 확인했으며 실행하지 않았다. 생성은 총 10회(행당 2회)다.
