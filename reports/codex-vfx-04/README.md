# CODEX-VFX-04 — Luna 새 기술 그림 후보

완료: **PNG 16개 + JSON 16개, 총 62프레임**. 모두 후보이며 게임에는 반영하지 않았다. 내장 `image_gen`을 사용했고, 사용자 첨부 4장을 모든 생성에 참조로 전달했다. 작은 상태 마크와 아이콘 5개만 Pillow로 원래 크기에 직접 그렸다.

## 규격 검사

| 파일군 | 전체 PNG | 프레임 | fps / 반복 | 앵커 |
|---|---|---|---|---|
| barrier A/B | 1536×256 | 6 × 256×256 | 10 / 예 | 128,128 |
| barrier_break A/B | 1536×256 | 6 × 256×256 | 24 / 아니오 | 128,128 |
| cyclone A/B | 1152×192 | 6 × 192×192 | 20 / 예 | 96,96 |
| warp A/B | 1536×256 | 6 × 256×256 | 24 / 아니오 | 128,128 |
| star_shot | 192×48 | 4 × 48×48 | 16 / 예 | 24,24 |
| star_big | 384×96 | 4 × 96×96 | 16 / 예 | 48,48 |
| star_mark | 24×24 | 1 | 정지 | 12,12 |
| 아이콘 5개 | 각각 40×40 | 1 | 정지 | 20,20 |

- **16/16 통과**: RGBA, alpha `{0,255}`, 모든 프레임 1px 테두리 비움, 투명 픽셀 RGB 0, 프레임 수·fps·앵커·반복 메타데이터 일치.
- 확대 0건, 잘린 불투명 픽셀 0개. 원화→최종 최대 배율 0.795. `fit-audit.json`에 모든 축소·배치 기록이 있다. 보드의 2배·4배와 카드 지정 회오리 표시 1.25배는 확인용 표시 배율이다.
- 방어막은 원화의 테두리 타원을 측정해 중심을 고정하고, 테두리 중심 반지름 104px + 얇은 외곽으로 카드의 약 210px 지름에 맞췄다. 별 장식은 테두리 밖으로 나온다. 초록 가이드 원은 정확히 반지름 105px이다.
- 파괴 첫 프레임은 같은 후보의 방어막 첫 프레임과 픽셀 단위로 동일하다. 후반 파편은 바깥쪽에 남도록 배치를 보정했다.
- 반복 6종 모두 빈 프레임 없음. 마지막→첫 프레임 픽셀 변화량 / 내부 전환 중앙값: 방어막 A 1.073, B 0.794; 회오리 A 0.736, B 0.428; 작은 별 0.984, 큰 별 1.149. **이 값은 연결부 진단이며 자연스러운 움직임을 보증하는 수치가 아니다.**
- 기본 생성의 회오리 A에 있던 밝은 내부 막은 추가 ImageGen 편집으로 제거했다. 작은 별 F4는 원화의 회전 방향 중복을 상하 반전으로 보정했다.

## 시각 검수와 한계

카드의 모든 사용 위치를 실제 Luna/Brave idle 프레임으로 합성하고 **각 항목의 모든 프레임을 4배로 직접 확인했다**. 방어막·파괴는 1배/2배/4배, 회오리는 몸 주변 효과 1.25배와 발사 효과 1배, 순간이동은 195×165 상자, 탄환은 33×33·60×60 상자, 상태 마크는 기존 코드의 발 위 121px, 아이콘은 48px HUD 슬롯의 4px 안쪽에 배치했다. `*-1x.png`, `*-2x.png`, `*-4x.png`가 대응 보드다.

보드는 **게임 스크린샷이 아니라 합성**이며 이펙트 가산 혼합을 근사했다. 어두운 배경은 실제 Alfheim 배경을 0.38 밝기로 낮췄다. 정적 PNG와 미리보기 JavaScript 구문을 검사했으며 **Godot 실행·게임 통합·사람의 재생감 평가는 하지 않았다**. `preview.html`은 외부 파일·서버 없이 열 수 있는 재생 보조 자료다.

## 재현과 인계

지정 Python에 `PYTHONDONTWRITEBYTECODE=1`을 설정한 뒤 `build.py` → `boards.py` → `verify.py` → `make_preview.py` 순서로 실행한다. 원화는 `art/raw/vfx-04/`에 보존하며 커밋 대상에서 제외했다.

`commit.ps1`은 **작성만 했으며 실행하지 않았다**. `delivery-files.txt`의 이번 파일과 작업 카드만 추가·커밋하도록 제한했다. 기존 다른 후보와 시작 시 이미 있던 미추적 파일은 대상이 아니다. `smash-nine-prototype/` 변경 없음.

남은 작업: 사용자가 A/B와 작은 그림을 선택 → 리드가 채택·연결 → 실제 경기에서 밝기, 반복 속도, 가림을 확인. 미납품 항목 없음.
