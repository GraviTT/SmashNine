# CODEX-ART-08B 리워크 이미지 생성 기록

도구: Codex 내장 `image_gen` (투명 배경 편집 모드). CLI/API와 외부 다운로드는 사용하지 않았다.

## Rio 남성

현재 v2 시트를 동작·배치 기준, 승인된 메인 일러스트를 의상·체형 기준으로 사용했다. 6×7 / 23프레임 구성과 오른쪽 방향을 유지하면서 머리를 전체 키의 약 1/3로 줄이고 몸통·다리를 늘린 3등신 픽셀 캐릭터로 다시 그리도록 요청했다. 검·망토·룬 방패, 네이비/시안 팔레트는 고정하고 투명 배경, 셀 주변 여백, 무색 테두리, 이웃 프레임 혼입 금지를 명시했다.

## Rio 여성

현재 v2 시트를 동작·배치 기준, 승인된 여성 메인 일러스트를 의상·체형 기준으로 사용했다. 남성과 같은 3등신 규격을 적용하되 긴 포니테일, 여성형 갑옷, 시안 대검과 망토를 보존했다. 6×7 / 23프레임, 투명 배경, 효과 비절단, 무색 테두리 조건을 동일하게 적용했다.

## Luna / Brave Luna

각 기존 시트와 Luna 메인 일러스트를 참조해 2.2등신, 6×7 / 23프레임, 투명 배경, 빨강·마젠타 매트 금지 조건으로 생성 시안을 만들었다. 다만 최종본은 생성 시안보다 기존 캐릭터 실루엣 보존이 낫다고 판단해 이 시안을 채택하지 않았고, 기존 v2 원본을 Godot `Image` API로 축소·정렬·프린지 제거했다.

## 공통 후처리

Godot `Image` API에서 최근접 축소, 순수 빨강 잔여 제거, 작은 고립 성분 제거, 바깥 2px 안전 링, 발 y=120, 불투명 중심 x≈64를 강제했다.
