## 측정과 육안 판정

- 전달한 14개 행은 전부 테두리 비움, 최소 4px 여백, 초록 번짐 0, 이진 알파, 여성 디테일 기준 73 이상을 통과했다.
- 4배 판 `review4x-base.png`, `review4x-moves-a.png`, `review4x-moves-b.png`에서 한 얼굴, 양손, 검 한 자루, 양쪽 부츠와 동작 의미를 전 프레임 확인했다.
- 이펙트는 그리지 않았다. `rune_shield`에 룬 원, `dimension_slash`에 잔상, `infinity_overdrive`에 궤도검이 없다.
- 단일 자세와 회전 자세의 머리 크롭은 `head_compare.png`, 전체 후보는 `overview.png`에 있다.

## 아직 잘못된 점

- `walk`: 보브 보정은 `+1,+2,−1,−2,+1,+2,0,−1px`로 ±3 안이고 7번은 지지발 1개다. 그러나 3번의 들린 발끝이 지면 판정 띠에 남아 `walk_feet.py`가 지지 run 2개를 검출했다. 3번은 3회 생성 상한에 도달했으므로 ART-59 규칙에 따라 **미전달**했다. `walk/best-attempt.png`, `onion.png`, `feet.json`에 남겼다.
- `attack`: 128px 셀 fit 예외 때문에 머리 자동 중앙값이 0.90이다. 더 키우면 4px 여백을 잃는다.
- `shield`: 3–6번은 버티기 구간이라 포즈 변화가 작다.

생성은 내장 ImageGen을 사용했고 사용·실패 원본은 `art/raw/rio-61b/`에 보존했다. 제품 연결과 Godot 실행은 카드 범위 밖이라 수행하지 않았다.
