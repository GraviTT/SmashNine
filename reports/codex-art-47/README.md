# CODEX-ART-47 결과

Frey, Luna, Brave Luna의 사용자 선택용 메인 아트 후보를 캐릭터별 2개씩 만들었다. 게임 프로젝트에는 적용하지 않았으며 `smash-nine-prototype/` 아래 파일은 변경하지 않았다. 생성에는 내장 이미지 도구를 사용했고, 실제로 사용한 생성본과 배경 정리용 중간본은 `art/raw/mainart-47/`에 보존했다.

세 캐릭터 모두 같은 선화 굵기, 셀 셰이딩과 제한된 부드러운 그라데이션, 채도 범위로 맞췄다. 다만 재질 특성상 Frey의 금속 표면은 Luna 계열의 천보다 대비와 세부 묘사가 조금 더 강하다.

## 측정한 값

- 모든 전신: `1024x1536`, `RGBA`, 알파 범위 `0..255`.
- 모든 얼굴: `256x256`, `RGBA`, 포즈별 정사각형 원본 영역에서 LANCZOS 축소.
- 전신 불투명 영역 높이: 여섯 후보 모두 `88.02%`.
- 위·아래 최소 여백: 모두 `92px`. 좌·우 최소 여백은 후보별 `35px` 이상.
- 캔버스 네 변의 비투명 픽셀: 모두 `0`.
- 제거한 초록 키 색과 일치하는 색이 투명 영역 2px 안에 남은 픽셀: 모두 `0`.
- 강한 초록 우세색이 투명 영역 2px 안에 남은 픽셀: 모두 `0`.
- 세부 수치와 후보별 소스 키 RGB는 `measurements.json`에 기록했다.

## 눈으로 확인한 항목

- 전신 6장을 원본 해상도로 확인했다.
- 얼굴 6장을 정확히 2배로 확대해 `inspection/faces-2x.png`에서 확인했다.
- 머리와 부츠, Frey의 검·방패, Luna의 지팡이, Brave Luna의 포니테일·건틀릿이 잘리지 않았다.
- 보이는 손은 손가락 수와 관절 연결을 확인했고, Brave Luna의 두 주먹은 끊기거나 합쳐지지 않았다.
- 얼굴 크롭은 눈이 대략 상단 40% 부근에 오고 머리와 어깨 일부가 함께 보이도록 포즈별로 잡았다. 이 항목은 자동 얼굴 인식 수치가 아니라 2배 확대 육안 판단이다.
- 배경 제거 뒤 체크무늬와 어두운 배경에서 가장자리를 확인했다. 측정상 키 색 잔류는 0이며, 보이는 어두운 외곽선은 생성 그림 자체의 선화다.

## 현재 상태

여섯 후보 제작과 카드의 크기·알파·잘림·키 색 잔류 검사는 완료했다. 이들은 선택 후보이므로 아직 게임 자산으로 채택되거나 설치된 상태는 아니다. 사용자가 후보를 고른 뒤 리드가 게임 파일에 적용해야 한다.
