# Soul crystal pixel art

`CODEX-ART-05A`에서 만든 소울 크리스털 오브젝트 애니메이션입니다.

## 파일과 사용법

- `soul_crystal.png` — 192×64, 48×64 셀 4개의 반짝임 루프입니다.
- `soul_crystal_shatter.png` — 192×64, 균열 → 분리 → 폭발 → 잔여 파편의 4프레임입니다.
- 모든 프레임은 셀 로컬 중심 x=24, 하단 y=56입니다. 중앙 피벗 Sprite2D라면 y 오프셋 -24로 하단을 원점에 맞출 수 있습니다.
- 최근접 필터와 반복 없음으로 임포트하며, 두 시트 모두 2배 픽셀 격자를 보존합니다.

## 생성 프롬프트

- 반짝임: `밝은 보라색 핵, 짙은 인디고 테두리, 각진 세로형 결정 군집. 진짜 투명 배경의 4열×1행. 실루엣·크기·중심·하단은 고정하고 면 하이라이트와 작은 광점만 순환.`
- 파괴: `같은 계열의 보라색 소울 크리스털이 4프레임에 걸쳐 갈라지는 애니메이션. 깊은 균열 → 큰 각진 조각 분리 → 흰보라 섬광과 외향 폭발 → 작게 사라지는 파편.`
- 공통 스타일: `2D 플랫폼 브롤러용 16비트 픽셀 아트, 제한 팔레트, 굵은 남색 외곽선, 안티앨리어싱/받침대/배경/텍스트/워터마크 없음.`

## 팔레트

짙은 인디고, 로열 퍼플, 마젠타 바이올렛, 옅은 라벤더, 거의 흰 하이라이트를 사용했습니다.

원본 생성 결과와 정확한 후처리 코드는 각각 `reports/codex-art-05a/source_*.png`, `tests/art_preview/monsters_a/build_assets.gd`에 있습니다.
