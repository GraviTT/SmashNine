# Nova

## Character Identity

- 분류: 슈퍼 히어로
- 역할: 중력 벡터 기반 공중 추격자
- 전투 방식: 현재 속도와 방향을 공격력으로 변환
- 기준 감각: 빠른 가속, 곡선 이동, 급정지 충격, 높은 조작 숙련도

노바는 별도 게이지 대신 현재 이동 속도를 자원으로 사용한다. 빠르게 움직일수록 몸 주변의 중력 잔상이 강해지고 J와 L의 판정 이동 거리, 피해, 범위와 넉백이 증가한다.

프레이와 브레이브 루나의 돌진은 이동과 공격이 한 기술에 묶여 있지만, 노바의 K는 공격 판정이 없는 순수 가속 기술이다. 플레이어가 K로 만든 속도를 J 또는 L로 직접 공격에 변환해야 한다.

## Momentum Rule

- 약 170 미만의 속도에서는 추가 보정 없음
- 속도가 약 170에서 700으로 증가할수록 공격이 단계 없이 연속적으로 강화
- 최대 보정 이후에는 추가 속도가 생겨도 공격 수치가 더 증가하지 않음
- 고속 상태에서는 청록색에서 금색으로 변하는 중력 잔상이 나타남
- UI 게이지는 사용하지 않으며 움직임과 잔상으로 현재 위력을 판단

## J - Vector Strike

### Neutral / Side J

현재 수평 또는 비행 방향을 따라 몸체 판정이 이동한다. 속도가 높을수록 이동 거리, 판정 크기, 피해와 넉백이 증가한다.

### Up J

중력을 위로 반전시키는 상승 타격이다. 노바도 상승하며 상대를 강제로 띄우기 때문에 공중 추격의 시작점으로 사용한다.

### Down J

지상에서는 노바 주변에 작은 중력 압축 충격을 발생시킨다. 현재 속도에 따라 반경과 밀어내기가 증가한다.

### Aerial Side J

현재 비행 궤도를 따라 판정이 이동한다. K 도중 사용하면 벡터 시프트를 취소하고 그 순간의 속도를 공격으로 변환한다.

### Aerial Up J

공중 상승 타격으로 상대를 위쪽으로 이어서 추격한다.

### Aerial Down J

노바가 빠르게 낙하하는 메테오 킥을 사용한다. 착지할 때까지 다른 행동이 잠기며, 착지 시 현재 낙하 관성에 비례한 원형 충격파가 발생한다.

## K - Vector Shift

입력한 상하좌우 또는 대각선 방향으로 약 0.22초 동안 노바 개인의 중력 방향을 바꾸고 빠르게 가속한다.

- 공격 판정 없음
- 이동 중 J 또는 L로 전환 가능
- 공중에서는 기본 1회 사용 가능
- 착지하면 공중 사용 횟수 회복
- 아무 방향도 입력하지 않으면 바라보는 방향으로 사용
- K 중에는 일반 수평 이동과 아래 방향 중력이 잠시 중단

## L - Gravity Brake

현재 속도를 즉시 0으로 만들고 잃은 운동량을 주변 중력 폭발로 방출한다.

- 저속에서는 작은 범위와 낮은 피해
- 고속에서는 최대 약 2배의 반경과 강한 피해·넉백
- 공중에서도 짧게 현재 위치에 고정된 뒤 발동
- 충분히 빠른 상태에서 적중하면 공중 K 사용 횟수를 1회 회복
- 여러 적을 맞혀도 한 번의 L에서 K 회복은 한 번만 적용

## Ultimate - Event Horizon: Gravity Slingshot

궁극기 버튼을 세 번 눌러 각 단계를 직접 발동하는 중력 투석 기술이다.

1. 첫 입력: 입력 방향의 고정된 위치에 중력핵을 생성한다. 노바의 이동은 유지된다.
2. 두 번째 입력: 그 순간의 위치에서 중력핵을 중심으로 공전을 시작한다.
3. 세 번째 입력: 현재 접선 방향으로 돌진하고, 적 또는 지형과 충돌하거나 최대 거리에 도달하면 중력 폭발을 일으킨다.

두 번째 입력 때 노바와 핵 사이의 거리가 공전 반경이 된다. 반경이 좁을수록 빠르게 회전하며 돌진 속도와 최대 거리도 증가하고, 반경이 넓을수록 회전과 돌진이 느리고 짧아진다. 공전 중에는 현재 접선부터 예상 종착점까지 주황색 예고선과 원형 표식이 계속 표시된다.

돌진 중에는 K를 한 번 사용할 수 있다. K 입력 방향으로 돌진 궤도를 즉시 꺾고 속도를 조금 더하지만, 돌진의 남은 시간은 초기 공전 성능을 따른다. 공전 또는 돌진 중 피격되면 궁극기가 취소되며 월드 충돌, 중력핵, 예고선과 공격 판정이 즉시 정리된다.

**궁극기 조정 2026-10-08:** 중력핵이 서 있는 동안 230px 안의 적을 핵 쪽으로 끌어당김(240), 돌진하는 순간 핵이 붕괴해 모인 적을 침(반경 118, 피해 18), 최종 폭발 34~46·반경 124~170(기존 22~31·108~152). 핵·폭발 아트. 돌진이 궤도의 접선(핵 반대쪽)으로 나가 끌어당긴 적을 놓치던 문제를 붕괴로 보완. 1회당 피해 5.6(1차 조정 뒤) → 평균 9.3(6.5~12.4로 크게 흔들림, 봇의 돌진 조준 영향). 공통(2026-10-08 루틴, D26): 시전하면 얼굴 컷인 띠·화면 번쩍임·흔들림, 궁극기 창 안의 적중은 히트스톱 2.2배, 이펙트 아트는 `assets/art/vfx/`.

## Combat Flow

```text
달리기 또는 낙하로 기본 속도 확보
-> K로 원하는 방향에 추가 가속
-> 공중 좌우 J로 관성을 공격으로 변환
-> 고속 L로 적을 밀고 K 사용 횟수 회복
-> 다시 K로 추격하거나 안전한 플랫폼으로 복귀
```

## Strengths And Weaknesses

- 강점: 자유로운 공중 진입, 추격, 플랫폼 간 이동, 고속 상태의 강한 공간 확보
- 약점: 정지 상태의 낮은 위력, K 자체의 무방비, 어려운 제동과 방향 예측, 높은 조작 난도
- 대응법: K 이동 방향을 읽고 공격을 비운 뒤 착지 지점을 노리거나, 고속 J와 L을 패링해 노바의 관성을 낭비시킨다.

## Prototype Tuning Checklist

- K의 가속이 너무 즉각적이거나 제어하기 어려운지 확인
- 공중 K 1회 제한이 넓은 렐름 이동에 충분한지 확인
- 저속 J가 쓸모없게 느껴지지 않는지 확인
- 고속 J의 판정 이동 거리와 넉백이 지나치지 않은지 확인
- L의 급정지가 조작 실수를 되돌리는 무료 탈출기가 되지 않는지 확인
- 고속 L 적중 후 K 회복이 무한 추격으로 이어지지 않는지 확인
- 공중 아래 J의 착지 잠금과 충격 범위가 적절한지 확인
- 중력핵 생성 후 이동해서 좁은 반경과 넓은 반경을 의도적으로 만들 수 있는지 확인
- 좁은 공전과 넓은 공전의 속도 차이가 과하거나 미미하지 않은지 확인
- 공전 중 예고선과 원형 종착점이 실제 돌진 방향과 거리를 읽기에 충분한지 확인
- 돌진 중 K 방향 전환이 강력하지만 조작 불가능할 정도로 급격하지 않은지 확인
