# 시안 월드컵

시안을 둘씩 나란히 재생해 더 나은 쪽을 고르는 페이지입니다. 결과와 메모는 기록되고, Claude가 그 기록을 읽고 판정합니다.

- **주소:** https://claude.ai/artifact/B6VxzHK5etStnhK7L3bFAx (소유자 전용 Artifact, `db` 기능)
- **요청:** 사용자, 2026-11-04.
  > 모션 뷰어를 더 간단히 하여 새로 하나를 만들 것. 인터넷에서 흔히 보이는 'XX 선택 월드컵' 같은 느낌으로, 두 시안을 비교해서 더 나은 시안을 선택하는 간단한 방식으로. 3개 이상의 시안은 모든 후보를 한번씩 리그 식으로 붙게 하여 점수제로 판단하고, 정하기 힘들면 비기는 것도 가능. 어느 부분은 A가 낫고 다른 부분은 B가 낫다 라고 코멘트도 남기기 가능. 이후 최종적으로 AI가 기록을 본 뒤 판단하게 한다.
- 모션 뷰어(`tools/motion_viewer/`)는 그대로 둡니다. 동작 전체 보기와 속도 채택은 모션 뷰어에서 하고, 후보 고르기는 여기서 합니다.

## 페이지가 하는 일

- **한 번에 한 경기:** A와 B를 같은 순간부터 함께 재생합니다.
  - 재생·멈춤, 처음부터, 속도(1·½·¼배), 크기(맞춤·1·2배, 픽셀 그대로)를 고를 수 있습니다.
  - 어느 시안이 왼쪽에 설지는 경기마다 정해져 있습니다. 같은 시안이 늘 왼쪽에 서지 않게 하려는 것입니다.
- **고르기:** "A가 낫다", "비김", "B가 낫다"를 누릅니다. 키보드로는 `←` `↓` `→`, 재생·멈춤은 `Space`, 처음부터는 `R`입니다.
- **메모:** 시안마다 "나은 점"을 적을 수 있고, 고를 때 함께 저장됩니다.
- **리그:** 시안이 셋 이상이면 모든 짝이 한 번씩 맞붙습니다(3개면 3경기, 4개면 6경기).
  - 이기면 3점, 비기면 1점입니다.
  - 리그 표, 경기 기록(누르면 다시 보고 바꿀 수 있음), AI 판정이 아래에 나옵니다.
- **로컬 미리보기**(`node tools/serve_web.js tools/pick_cup/dist 8074`, launch 이름 `pick-cup`)에서는 기록이 저장되지 않는다고 표시됩니다.

## 라운드 만들기 (리드)

1. **영상을 만듭니다.** 같은 장면을 시안마다 같은 길이로 녹화합니다.
   - "지금"은 실제 지금 게임이어야 합니다. 옛 시험 장면을 쓰지 않습니다(`reports/debate-pixelfx-basic/` D2).
   - 기본은 경기 카메라(0.85배) 녹화입니다. 페이지의 크기 버튼으로 키워 봅니다.
   - 녹화 예: `smash-nine-prototype/tests/analysis/lead/cup_step_dust_capture.gd`(창 모드)
   - 파일 위치: `art/cup/<라운드>/<항목>/<시안>.mp4`
   - 형식: H.264, 30fps, 짝수 크기
2. **라운드 파일을 씁니다:** `tools/pick_cup/rounds/<라운드>.json`
   ```json
   {"round": "2026-11-04", "title": "첫 라운드", "items": [
     {"id": "frey-step-dust-pace", "title": "Frey 발걸음 먼지 길이", "question": "무엇을 보고 고를지 한두 문장",
      "candidates": [{"id": "one-step", "name": "한 걸음", "desc": "무엇이 다른지", "media": "art/cup/2026-11-04/frey-step-dust-pace/one-step.mp4"}]}]}
   ```
   - id는 영문·숫자·`_ . ~ : @ + -`만 씁니다. 기록 문서 id에 그대로 들어갑니다.
   - 시안은 항목마다 2개 이상입니다.
   - 한 라운드는 작게 잡습니다(항목 2~3개).
3. **만들고 게시합니다.**
   - `node tools/pick_cup/build.mjs [rounds/<파일>]`를 돌립니다. 인자가 없으면 가장 최근 라운드입니다. 결과는 `dist/`에 나옵니다(git 제외).
   - 위 주소에 다시 게시합니다. `file_path`는 `dist/index.html`, `root`는 `tools/pick_cup/dist`, `files`는 `dist/files.json` 목록입니다.
   - `capabilities`는 빼서 `db`를 유지합니다.
   - 라운드를 바꿔도 이전 라운드의 기록은 데이터베이스에 남습니다(문서 id 앞에 라운드).

## 기록과 판정 (Claude)

- **경기 기록:** 컬렉션 `cup_matches`
  - 문서 id: `<라운드>~<항목>~<a>~<b>` (`a`·`b`는 시안 id, 사전순)
  - 필드: `round`, `item`, `a`, `b`, `left`(왼쪽에 선 시안), `winner`(시안 id 또는 `draw`), `notes`({시안 id: 나은 점}), `at`
- **읽기:** `ArtifactData` `query`(collection `cup_matches`, `where round == <라운드>`)
  - 리그 표를 다시 계산하고 메모를 읽습니다.
  - 점수가 같거나 메모가 갈리면 메모에 적힌 이유를 따라 판단합니다. 예: "발이 닿는 순간은 A, 여운은 B" → 두 장점을 합친 수정안
- **판정 남기기:** 컬렉션 `cup_verdicts`
  - 문서 id: `<라운드>~<항목>`
  - 필드: `round`, `item`, `choice`(시안 id), `reason`(한국어 한두 문장), `at`
  - 페이지의 "AI 판정" 칸에 바로 보입니다.
- **판정된 것만 게임에 넣습니다.** 넣은 뒤에는 보고서에 기록과 판정을 적습니다.
